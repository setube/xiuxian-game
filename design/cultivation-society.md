# 修仙界与凡间的关系（30.md 地基，2026-09-09）

> 31.md 末尾自己指出来的：「这个关系不定，后面的宗门、坊市、战争、杀人、修士身份、修仙地域都会各自往不同方向跑。」
> 五份修仙文档的共同方案把它列为第 0 步。现在三个会话同时在修仙这一侧施工（29 散修／宗门、31 材料／功法、32 修行之后凡人关系），
> 这份文档是让它们不各造一套的那张纸。**每一条都标了出处**：已拍板的、内容里已经这样的、我按假设写的、需用户决策的。

## 一句话

**寄生、嵌入、不显形。** 修仙界不管凡间，也不被凡间管；它靠凡间活（药、粮、人），凡间不知道它在。
一个凡人看见的永远是一个人——不老的客人、镇西的郎中、下山取药的年轻人——不是一个组织。

这句话不是新原则，是 30.md 第二十三节「凡人与修士不能突然断开」加 27.md 拍板的公开度，落到同一句上。

## 四条施工规矩（从前两片攒出来的）

1. **世界事实写在人身上，不写成一张宗门表。** 「药庐那位是山上的人」是 `Cultivator.history` 上的一页，不是 `Sect.members`。
   「山上」眼下只是一个 `place: '云台'` 加几个人的过去；它叫什么、几个人、什么规矩，等内容要问的那一天再长——
   第一个使用者大概是 29 的「上山」那一卷（`going-up.ts`），宗门若要成为一户，往 `House` 上长（成员≠亲人那条线是现成的），别先建 `Sect`。
2. **凡人能看见的只有一个人和他手里的东西。** 一个下来取药的年轻人和一只篓子、一个不老的客人、一味认不出的药（31 第一片）。
   看见的是征象，读出来的意思多半是错的（`bearing.sees` / `reads`）。别让正文替凡人说出「宗门」两个字。
3. **话到这儿为止，是这个世界的形状。** 「上头问起你了。」你等他往下说，他没有往下说；「石苁。」他说完接着翻他的药。
   两处是同一件事的两次实现：凡间能得到的答案永远只有半句，而且没有人会补全它。往下推成一条鉴定流程、
   一场解释，就把「不显形」推翻了。写到半句就停，让沉默自己站着。
4. **门内的规矩要有门内的后果。** 「别出去乱说」不是一句嘱咐，是一条会咬人的规矩：说出去了，那个人不再理你——
   后果落在关系上（`footing` 回到「不理会」），不落在凡间的任何账上。凡间不知道发生过什么，那正是「不显形」的意思。
   「凡间的账」指他在凡间的处境——家境、名声、里长的册子、别人待他的态度；**他自己的年表不是处境，是记忆**。
   有人特意来问过、他瞒住了，是他这一生里发生过的事，年表照记（「{call:spouse}问起过药庐那边。你没说。」），
   跟「凡间不知道那个秘密存在」不冲突（79 与 22 在 2026-09-09 辨清的）。

## 接口给三个同伴

- **29（79，散修／宗门）**：入口只有一个，`known-on-the-mountain`（山上知道有你这么个人）。「上山」之后看见什么由你定；上头那张表里「征用」「规矩」「法律」三行是你那一卷会碰的边。
- **31（17，材料／功法）**：凡间这一侧能到的最高一级是「拿给药庐那位看，他说了个名字就低头称药」——
  `finding:named` 已经做到这一级（「石苁。石头缝里长的，不烂」，说完接着翻药），**这条线在凡间到顶了**（17 定的，2026-09-09）。
  九级链第五级起要的「愿意坐下来讲的人」在凡间没有：不是陶仲（说完就走），也不是下山取药的那个人——
  他没有资格挑人，让他讲一味药的用途产地就给了他一个「懂行的人」的角色；而且 `mountain:again` 的落点
  「你等他往下说。他没有往下说」，分量正来自那个沉默，同一卷里再让人开口讲药会冲淡它。
  **触发条件写死：「上山」那一册出现、里头有一个愿意坐下来讲的人，第五级才有立足点。** 在那之前不硬造。
- **32（52，修行之后凡人关系）**：「不显形」意味着修行之后回村，村里人看见的仍是一个人：不老是征象，「修士」两个字他们说不出。
  你那片的入口是壮年那一卷「山上的人问起过你。此后再没有下文」那一句往后。

## 寿命：延寿 ≠ 不老 ≠ 长生（用户拍板，`cultivation-rulings.md` 二）

```
延寿    寿命上限增加            活到一百二十岁，但明显衰老
不老    衰老速度显著改变        活了两百年，外表停在某个年龄段
长生    不再受凡人寿命尺度支配  数百年仍然继续生活
```

三层先后出现、不等价、不是一条自动的阶梯；**不许按境界填表**（筑基 = 150 岁那种）；长生者照样会死（被杀、毁道基、重伤、走火入魔、寿元耗尽、特殊代价）。
长生是**社会事实**不是角色属性：有人知道她是修士，有人只觉得她保养得好，有人怀疑她不老，有人已经确定她不是凡人——第三片 `he-does-not-age` 落在中间那一层（不老），读法就是这四种里的两种。

**引擎里现在的样子（2026-09-10，52 的 `8907d8b` + 22 的配套一笔）**：`realm` 不再免老死；天年是写在人身上的世界事实——`Cultivator.span`（山道上那个 200／观里那位 200／药庐那位 200／下山的那个 160，各标了是延寿还是不老），入册时带进 `Person.span`；老病的起点跟着天年走（`pivot = max(45, span − 45)`，凡人一个数不变）；师承链上凡是他在场的事件都问一句 `alive`。四个数都超过任何一世能活到的岁数，今天的行为不变，变的是「不老死」从一句 `if` 挪到了人身上。**`span` 只落得了「延寿」那一层**；「不老」那一层 52 同日补上了（`0cdf9bb`／`3a0c6e7`）：`Person.seemsAge`（看着多大，写在人身上——山道上那个 28、药庐那位 45、下山的那个 22；观里那位有意不写，他是延寿不是不老）+ `Condition.unaged { who, by, knownFor }`（他看着比岁数年轻多少、认识他多少年了）——「他不老」头一次见面就成立，察觉要等交情够长，`mountain:unaged` 里三句按二十／三十／四十年读；`still.ts` 那一册（五十岁后）写的是玩家自己进入另一个时间尺度。玩家侧仍只有 `extendSpan`（延寿），第一个正向使用者是 `2584343`（守着那件事十几年）。
