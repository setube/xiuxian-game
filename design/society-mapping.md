# 社会事实 → 游戏模型：映射表

> 底座（`ming-society.md`）说的是「世界是什么样」。这张表问的是另一件事：
> **这个历史事实在游戏里究竟起什么作用？** 问不出来的，不进模型。
>
> 六列照用户定的格式：现实概念 → 需不需要表达 → 由哪个数据承载 → 影响什么 → 目前已有 → 目前缺口。
> 加了第七列「顺序」——它来自底座里「第一个使用者已在等」那条纪律，不来自层级图。

**「目前已有」一列是对着代码查的，不是凭印象填的**（2026-09-06 的库）。凡写 ✓ 的，都能在 `src/` 里指出那一格；凡写「无」的，都 grep 过。

「需要」一列四档：**需要**（有内容在等或用户点名）／**弱**（有史料依据，但库里没有任何东西问它）／**已有**（早就在）／**暂不**（没有使用者，不建）。

## 读这张表的两个提醒

**「需要」不等于「现在建」。** 表里标「需要」的有十四行，标了顺序的只有六个。其余的「需要」是说它有使用者在等，但排在后面——因为每一次建格子都要跑全套门禁、改存档版本、写判据，一次建一个才看得清它逼出了什么。

**「目前已有」会漂。** 这一列是 2026-09-06 对着代码填的。下一次改完代码，回来改这一列，不改这一列就别信它——它跟门禁里那些实测数是一样的东西，没人复核就会安静地变成假话。
