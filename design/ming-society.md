> 它不回答「游戏该怎么做」。设计从第二部分的审查表里长出来，不从这里。

## 〇、怎么读这份文档

### 四种材料，四个标记

每一条陈述前面都挂一个标记，**没挂标记的句子不算数**：

| 标记 | 意思 | 能拿来做什么 |
| --- | --- | --- |
| 【史料】 | 一手文献明确写着。**原文本次核过的加 ✓**，没核过原文但确信存在的写「待核原文」 | 当规则用。内容可以直接建立在它上头 |
| 【推断】 | 学界通说，或从史料合理推出来的；史料本身没有一句直接这么说 | 当默认用。有人拿出反例就得让 |
| 【文学】 | 出自小说、戏曲、笔记里的描写 | 当**语气和想象方式**用，**不当统计事实**。「小说里这么写」只说明当时人这么想象 |
| 【抽象】 | 明知与史实不同，为了游戏合理简化 | 要写明**简化掉了什么**，将来才知道从哪儿补 |
| 【待核】 | 用户转引、本文作者记不准、或来源可疑 | 不能建内容。要么核了升级，要么删 |

这套标记也约束这份文档自己：本次能核到原文的只有三处（见第十节），其余凭训练记忆写下的一律标「待核原文」。**把没核过的东西写成 ✓，就是这份文档存在的理由的反面。**

### 一条纪律：先有使用者，再抽象

每一层的末尾都有一段「第一个使用者」。它回答：**库里现在有没有一句话、一卷内容，因为少了这一层而写不出来或者写错了。** 有，才建；没有，先写那一卷内容，让它逼出需要哪些格子。（这条纪律本项目已经踩实过一次：先造的四层阶梯，第四层其实在另一条轴上。）

### 参照时段：嘉靖—万历（约 1520–1620）——已定

明 276 年不是一个模板。洪武朝的里甲严密、户籍不动、实物赋役，和万历朝的白银流通、市镇勃兴、户籍松弛、宗室贫困化，是两个社会。**混用它们，世界就会自相矛盾**（一边是「不许离乡」，一边是「出门做工」）。

本文取嘉靖—万历为参照，理由三条：史料最厚（《宛署杂记》《万历野获编》《帝京景物略》和大部分白话小说都是这一段）；社会流动性最适合「人生模拟」（商业、雇工、流民、士绅、宗室下层都活跃）；库里已有内容（粮价、出门做工、铺面）本来就是这一段的样子。【抽象·用户 2026-09-06 定】

**定的是参照，不是时间轴。** 王朝架空，不锁在嘉靖某一年，也不用真实年号做纪年——凡户籍、称谓、城乡、服饰、饮食、交通、市场、官府、科举、宗室、刑律，优先拿这一段的材料作依据；年号与皇帝另有一套随机但合制度的王朝史（见第十一节）。这样历史质感留住了，后面修仙世界的自由度也留住了。

## 一、时代

- 【史料·待核原文】赋役：洪武至正统以实物和力役为主；嘉靖以后「一条鞭法」渐行，役折银、赋并征，万历九年（1581）张居正推行全国。→ 参照万历，则**一个农户头上的负担主要是银子，不是去服役的人**；但军户勾补、驿递、里甲正役仍在。
- 【史料·待核原文】货币：白银与铜钱并行，大宗用银、日用用钱；粮价以「石」计。库里 `grain` 那把刻度对应的是「一石米多少钱」这件事的变动。
- 【推断】人口流动：万历朝流动人口远多于洪武朝——佣工、商贩、流民、逃军、游方僧道。「一辈子没出过村」在万历朝是**多数人**但不是**全部人**。
- 【抽象】本世界架空：四州十府沿一条大江。它借的是明代的**制度和生活**，不借明代的**地名和年号**。年号随机生成（第十一节）；京城正式名称定为**「京师」**，民间说京城、城里、京里——不再叫「天启」，那个词既是熹宗的年号又像一座城的名字，两条线搅在一起。【史料·待核原文，《明史·地理志》】永乐十九年改北京为京师，正统年间重定，「京师」本身就是都城的正式称呼。哪天写迁都、两京、行在，才让这个称号随世界事件变。（用户 2026-09-06 定）

**第一个使用者**：已经存在——`world-events.ts` 的粮价/粮荒/囤积/平粜四条，全是货币化粮食市场才有的事，它们已经默认了万历朝。时段不定下来，这四条和「不许离乡」那类内容迟早打架。

## 二、地域与聚落

### 2.1 行政层级 【史料·待核原文，《明史·地理志》】

```
京师 / 南京
  布政使司（省）　　　　　　　　　　　　　十三布政使司 + 两直隶
    府　　　　　　　　　　　　　　　　　　知府
      直隶州 / 散州　　　　　　　　　　　知州。州在府之下，不在府之上
        县　　　　　　　　　　　　　　　　知县、县丞、主簿、典史
          乡 · 都 / 图 · 里（110 户）· 甲（10 户）　　里长、甲首轮役
城内另一套：　坊 — 铺（或牌）　　　　　　　　　　　坊长、铺长 / 总甲
```

- 【史料 ✓《宛署杂记》卷五「街道」】京城：「城内地方以坊为纲，惟西城全属宛平，其中、北、南三城，则与大兴分治。」「每坊铺舍多寡，视廛居有差。总计坊凡十有三。其以胡同名者，凡三百一十二。」胡同名例：指挥营胡同、草场胡同、宫墙夹道街、三义庙街、官菜园、臭皮胡同、河漕东大街、石老娘胡同、青塔寺胡同。
  → **空间自带社会信息**：以军营、草场、庙、菜园、河漕、行业、某人宅第命名。一个孩子说「我住臭皮胡同」，别人立刻知道那一带是干什么的。
- 【史料·待核原文】皇城 ⊃ 宫城（紫禁城）。东宫在宫城内。「皇城 · 东宫」这个门牌把两层写成一层。

### 2.2 京城 【史料 ✓ + 文学】

- 【史料 ✓】宛平、大兴两县分治京城，县衙在城里。**京城居民在户籍上是宛平县或大兴县的民。**
- 【史料·待核原文】京城里没有藩王府——亲王成年之国，留京的是未就藩的皇子、公主府（驸马都尉）、勋戚宅第（公侯伯）、在京官员。
- 【文学·《帝京景物略》待核】灯市、庙会、园林、寺观、城外风景。这本书适合做**京城的季节和空间感**，不适合做人口统计。
- 【推断】京城的「普通人」：铺户（承买办差役）、军户（京营）、匠户（住坐匠）、贩夫、佣工、乞丐（养济院）。《宛署杂记》有养济院、铺行、宫庄、差役的记载【待核卷次】。

### 2.3 府城、县城 【推断 + 史料待核】

- 衙署区（府衙/县衙、仓、狱）、学宫（府学/县学，有生员）、城隍庙、市（常市，非集期）、寺观、坊巷、城门与**关厢**（城外附郭，商业往往比城里旺）。
- 【推断】府城有府学，县城有县学；院试在府城考（提学官按临）——库里 `youth:exam` 写「县里贴出告示，今年开院试」「去县学」，院试是**府一级**，县考的是县试。见审查表。

### 2.4 镇 【史料·待核，明代市镇研究通说】

- 明中后期市镇勃兴，尤其江南。镇不是行政单位：没有知镇，可能有巡检司或税课局。镇靠**水路节点 + 一两种主导行业**立住（丝、布、米、盐、瓷）。
- 有固定集期（「逢三六九」）的叫集/墟；常市的叫镇。**「镇上的集照常开」这句话在镇和集之间混了**，但作为口语可以接受。
- 【推断】村到镇的距离决定了「去镇上」是半天的事还是一天的事，也决定了这个村的孩子多久见一次外乡人。

### 2.5 村 【推断】

- 里甲编户；水井、社（土地）、祠庙、场院、牛栏柴垛；几户大户、多数普通人家、零散小路。
- **村与村的气质不同来自四件事**：交通位置（河道/官道/山里）、水（争水是最常见的讼）、宗族强弱（南强北弱）、有没有大户（佃农多的村是另一种村）。这不是美术，是人口流动与经济结构。
- 【推断】灾年之后的村：逃户、荒地、外来流民；治安变差；守夜。库里 `order`/`exodus` 已在模拟这一层，但它作用在**府**上，村与村之间没有分别。

### 2.6 南北 【推断 + 书目】

- 南方稻作、水乡、宗族强、砖木房、菜油；北方旱作、土坯房、麻油/豆油、宗族弱、军户多。语言不同——库里 `address.ts` 已经把「教养」做成一层，**「地域语言」还没有任何一格**。
- 【书目】陈宝良《明代社会生活史》专章讨论南北与地区差异【章节待核】。

### 2.7 目标形状：三层，两套 【抽象·用户 2026-09-06 定】

不做一个 `locationType`。至少拆成三层：

```
行政层级　　府 / 州 / 县　　　　　　　　　　　　官府的划法：谁管你、去哪儿交粮、去哪儿考试
聚落　　　　城 / 镇 / 村　　　　　　　　　　　　人口的划法：多久见一次外乡人、出门是上街还是去镇上
具体地点　　坊 / 街 / 巷 / 市 / 店 / 府第 / 寺观 / 田　　　脚下那一处
```

而且**京城和乡下是两套不同的层次**，不是同一棵树的两枝：

```
京城　→　某坊　→　某街／胡同　→　某宅
某府　→　某县　→　某镇　→　某村
```

《宛署杂记》那一卷（2.1 ✓）呈现的正是这个：北京不是一个「城市生物群系」，是坊、街、胡同、铺舍加不同人口和功能拼成的碎空间。「京城里、城里、县里、乡里、镇里、村里」六个词落在这三层的不同格上，**不是六张地图**。

**县、镇、村、坊在世界里不存在为结构**，只存在为正文里的词。
- 已有内容在用世界里没有的东西：`encounters` 五处「邻村」、`hardship` 六处「邻县」、`informants` 的「邻居说」、`days.ts` 人人可点的「去镇上」。**这些是第一个使用者**——它们说明缺的不是「地图」，是「这个村离什么近、旁边是谁」这两格。
- 「京城不是换地图」的第一个使用者：`court` 出身 + `royal.ts`。它们已经在用「宫墙」「通传」「钦天监」，但世界层给的门牌是「天启 · 皇城 · 东宫」——只有一个字符串，没有坊、没有宛平县、没有宫城/皇城之分。

## 三、户籍与身份

### 3.1 籍 【史料】

- 【史料·待核原文，《大明律·户律·户役·人户以籍为定》】「凡军、民、驿、灶、医、卜、工、乐诸色人户，并以籍为定。」籍世袭，改籍要官方允准，冒籍、脱籍有罪。
- 【史料·待核原文】民户占绝大多数；军户（卫所世袭，勾补）、匠户（轮班匠 / 住坐匠）、灶户（盐）、医户、乐户（贱籍）、僧道（度牒）。
- 【史料·待核卷次，《宛署杂记》有「铺行」】城市商铺登记为**铺户**，承担「买办」差役（官府向铺户征购物料）。**商人没有「商户」这个籍**：城里是铺户（仍属民籍，但承铺行差），乡镇是民户。
- 【史料·待核原文】匠籍：嘉靖四十一年（1562）班匠银全面推行，轮班匠以银代役，匠籍名存实亡；住坐匠仍在京。→ **万历朝一个乡下木匠，多半是民户**，「匠户」这个籍主要还挂在那些祖上被编入匠籍的人家头上，而且他们未必还在做木工。
- 【推断】医户：确有其籍（供太医院、地方医学），但**一间镇上药铺**未必是医户——更可能是民户/铺户里做药材生意的人家。

### 3.2 良贱 【史料·待核原文】

- 贱籍/贱役：奴婢、娼优、乐户、隶卒（衙门里的皂隶、快手、民壮、门子等**衙役**）。娼优乐户之家不得应试【史料·待核原文，《大明会典》科举条】。**衙役子孙能否应试，明代规定不如清代明确**——清律明列皂隶、马快等子孙三代不得应试，明代文献里这一条要另核。**不要拿一个模糊的「衙役」概念直接推出一句永久世袭禁令**（用户 2026-09-06 明令）。
- → **「当差」两个字要小心**：明代口语里「当差」既可以指做衙役（贱役），也可以泛指在衙门里服务；而库里 `office` 这一行写的是「府衙当差，八品」——八品是**官**（府经历正八品、县丞正八品），不是役。官与役在地位、财产、教育、婚姻圈、子女出路、跟普通人的关系、衙门内的权限上全不一样，不能共用一个词。**已定：拆成两行——官与役——不二选一**（见审查表）。

### 3.3 宗室 【史料 ✓《明会典》卷五十三 礼部 · 王国礼一 · 封爵】

```
亲王　　　　　　金册金宝
　嫡长子　　　　年及十岁，立为王世子，授金册金宝
　次嫡子及庶子　年至十岁，封郡王，授镀金银册银印
　　郡王之子　　镇国将军　　　（初三品，永乐后从一品）
　　　孙　　　　辅国将军　　　（从二品）
　　　曾孙　　　奉国将军　　　（从三品）
　　　玄孙　　　镇国中尉　　　（从四品）
　　　五世孙　　辅国中尉　　　（从五品）
　　　六世以下　奉国中尉　　　（从六品）
女：郡主 / 县主 / 郡君 / 县君 / 乡君　依次递降；靖江王府比郡王再减一等
妻封号（弘治十年）：妃 / 夫人 / 淑人 / 恭人 / 宜人 / 安人；「妾媵不封」
```

- 【史料·待核原文，《明史·职官志》】亲王成年**之国**（就藩），王府建在封地府城；府有长史司（长史、审理、典膳、奉祠、纪善、教授……）、仪卫司、护卫（永乐后多裁）。**王府在府城里是一整个衙门 + 一整个家**。
- 【史料·待核原文】宗室不得应科举、不得从事士农工商，靠禄米；万历二十二三年间《宗藩条例》/开放宗室应试（年份待核）。**万历朝下层宗室（将军、中尉一级）大量贫困**，禄米拖欠数年，有沦为佣工、乞丐、犯罪者。《万历野获编·宗藩》有多条【待核】。
- 【推断】皇子：未封王前居宫中，由乳母、宫人、内侍环绕；年长**出阁讲学**；封王后就藩。太子居东宫。
- → **「宫里」和「王府」是两种生活**：一个在宫城，父亲是皇帝，见面要通传，教育是出阁讲学、翰林侍讲；一个在某府城，父亲是亲王，有自己的官属，教育是王府教授，且**王府本身就是那座府城的一部分**——世子出门就是府城的街。库里 `living: palace` 把两者写成一种。
- → 宗室内部也不是一种生活：亲王府、郡王府、和一个欠了六年禄米的奉国中尉，是三种。库里 `manor`/`court` 两行只覆盖最上头的两种。

### 3.4 士绅 【推断 + 史料待核】

- 生员（秀才）：免本身徭役、优免二丁；见官不跪；犯事先革功名再问。举人、进士、乡宦（致仕官）。**「官宦之家」= 家里有功名或有官职的人**，八品官的儿子是官宦子弟，衙役的儿子不是。
- 【推断】官宦之家的孩子：请西席（库里已有 `tutor` 一节，好），不与坊巷孩子玩（库里已写「窗外能听见巷子里别的孩子在跑。你不认得他们」，好）。

### 现状与第一个使用者

- `census` 四格（民户/匠户/医户/宗室）大方向对；「木工→匠户」「药铺→医户」两处**推断过强**，「布庄/客栈/酒楼→民户」漏了铺户这一层。这四格眼下**零个条件读者**（`scripts/household.ts` 盯着这个零），所以改不改暂时没有内容后果——第一个读者出现时再一并纠。
- `station: '仕宦'` + `livelihood: '当差'` 是词义冲突，**有现实后果**：将来写衙役人家那一卷时，这一行不知道自己是哪一边。已定拆开。

## 四、家庭、家业与物质条件

### 4.1 家庭结构 【推断 + 书目】

- 核心家庭为主；联合家庭见于富户、宗族强的地区。分家。妾（富户）。**过房 / 乞养**是常态——常到《大明律》要专门防有人「假以乞养过房为名买良家子女转卖」【史料 ✓，见 6.1】。
- 【史料·待核原文】《大明律》里「雇工人」是一种法律身份（雇工人殴家长加重，家长殴雇工人减轻），长工与家庭之间是半依附关系。
- 库里 `circumstances.ts` 十种境况（父母俱在/有兄姐/丧母/丧父/长姐/兄/叔父/寺/乞丐/战乱失散）方向对；**缺**：过房给族人、跟祖父母过、母亲改嫁带走/留下。这三种在明代都比「老乞丐捡去」常见得多【推断】。

### 4.2 生计与财富 【推断】

- 农：佃户 / 自耕农 / 半自耕 / 地主。**佃户与自耕农是两种人生**（租、押、灾年谁先饿），库里 `farm` 一行没有这条分别。
- 工：匠人（木、铁、瓦、篾、织、染）；佣工（长工、短工、日工——库里 `day-labour` 已有）。
- 商：铺户（有铺面）、行商（走的）、牙人（中介）、脚夫。
- 【推断】财富不是一条线：**有田没钱**（自耕农）和**有钱没田**（小铺户）是两种「不宽裕」。库里 `standing` 一把 0–100 的刻度把两者压成一个数——作为隐藏刻度可以接受，但正文不能反过来从这个数推「他家有田」。

### 4.3 照明 【推断 + 用户转引待核】

- 【推断·通识】灯油：菜油（南）、豆油、麻油（北）、桐油（照明，气味大）；蜡烛：蜂蜡、白蜡（虫白蜡明代已普及，仍贵），**蜡烛是富户和礼仪用品**，寻常人家点油灯，穷家不点。
- 【待核·用户转引「明代浙江乡村」材料】「贫者不能得油」，豆油可点灯而极贫之家连食用油都缺。方向与通识一致，**原文出处未核**，不能单凭它建内容。
- → 设计含义（【抽象】，留给内容层）：照明是**连续分布**不是开关——极贫早睡/借火/炉火余光；普通农户有灯但省着；小康夜里能纺织读书；富户多灯有烛。夜里屋里亮着灯是一个**信号**（在做事 / 有客 / 比邻家富 / 出了事）。
- **第一个使用者：眼下没有。** 库里没有一卷内容发生在「夜里」并且依赖灯。先写那一卷（守夜、夜读、守灵、夜里有人敲门），再看它需要哪几格。

### 4.4 衣食住行 【书目·伊永文《明代衣食住行》待核章节】

- 食：南米北面；肉少，逢节才有；盐、酱、腌菜；茶。饭桌上有没有肉、粥稀不稀，库里已当征象用（好）。
- 衣：棉布普及（明代棉布取代麻）；颜色和料子有禁令（庶民不得用某些颜色、纹样）【史料·待核原文，《大明会典·冠服》】。
- 住：北方土坯 / 南方砖木；一间到几间；「两进有口井」是小康以上【推断】。库里 `fallen` 写「城南一处小院，两进，有口井」——对削爵之家是合理的落差。
- 行：步行为主；驿路、官道；水路是南方的主干；出远门要路引【史料·待核原文，《大明律·兵律·关津》】——**「出门做工」在制度上要有路引**，万历朝执行松弛，但被盘问是可能的。

### 现状与第一个使用者

- 物质条件在库里只有 `standing`（隐藏）和 `outlook`（五句话）。这**够用**——直到有内容要写「夜里」「穿什么」「住几间」。别先造格子。

## 五、社会关系

### 5.1 邻里 【史料 + 推断】

- 【史料·待核原文】里甲：110 户为一里，推丁粮多者 10 户为里长，余 100 户为 10 甲；里长甲首轮流应役（催粮、勾摄）。**邻居首先是同一里甲的人**，互相有连带责任。
- 【史料·待核原文，洪武三十一年《教民榜文》】里老人：「民间户婚、田土、斗殴、相争一切小事，不许辄便告官，务要经由本里老人、里甲断决」；申明亭（张贴犯人姓名、调处纠纷）、旌善亭（表彰）。→ **邻里纠纷多到官方要设一层机制专门处理它**。这是「邻居不可能都是好人」最硬的一条依据。
- 【史料·待核条目】《大明律》多处以「邻佑」「四邻」为见证或连坐对象（如窝藏、私盐、丧葬不报）。→ 邻居是**法律关系**：他见过你家的事，可以作证，也可以告发。
- 【推断】互助：借农具、借粮、帮工、送葬、乡约、社仓；纠纷：田界、水（灌溉）、债、宅基、鸡犬、闲话、婚事。**同一对邻居可以既互助又有讼。**
- 【推断】邻里关系不是一个标签，是一叠事：世交 / 有恩 / 有怨 / 有债 / 通婚 / 竞争 / 互相看不顺眼——而且**跨代**：祖辈世交、父辈因田翻脸，这两件事同时成立。

### 5.2 宗族 【推断 + 书目】

- 南方（徽州、福建、江西、广东）宗族强：祠堂、族田、族谱、族长调处、族规惩戒；北方弱。「本家」在南方是一个实体，在北方多半只是同姓。

### 5.3 世交、世仇、恩、怨、债 【史料（文书）+ 文学】

- 【史料·待核，徽州文书研究】契约文书（卖田契、借约、典契）、分家书、讼案，是跨家关系留下痕迹的一手材料。**债是最常见的跨家关系**——借约上有中人、保人，一张借约牵三家。
- 【文学】「两家世仇」「祖上有恩」作为**桥段**在小说里极常见（《三言二拍》），作为**统计**没有依据。它告诉我们当时人怎么想象人情，不告诉我们有几成人家有世仇。
- → 世界先于玩家：玩家先撞见一个老人，后来才听说「你爹年轻时和他哥打过一场田产官司」，再后来「你祖父和他祖父就是仇家」。这要求**关系存在于两个 NPC 之间、且带年份**——库里 `Relation` 的 `from/to/since/until` 结构本来就装得下，只是内容全从 `me` 出发。

### 现状与第一个使用者

- **邻居在库里不存在为人**。`Bond` 里没有「邻」；「邻居说」「村里排了守夜的」「同龄的孩子还在私塾」都有说话人却没有人。**这是最明确的第一个使用者**：已有正文在等着几个有名有姓的邻居。
- 「仇」这条边全库零使用者，「友」一处（`royal.ts`）。恩/怨/债/纠纷/世交/通婚都没有边。**不要一次加七种边**——先写一卷「借扁担没还」或「田界」，看它需要哪一种。
- 关系只从 `me` 出发。世交世仇要 NPC↔NPC 的边——**先写那一卷**，让它逼出「两家之间」这一层需要什么。

## 六、风险

### 6.1 拐卖 【史料 ✓《大明律》卷十八 刑律 · 盗贼 · 略人略卖人】

原文要点（本次核过）：
- 「凡设方略而诱取良人，及略卖良人为奴婢者」杖一百流三千里；为妻妾子孙者杖一百徒三年；因而伤人者绞，杀人者斩。**「被略之人不坐，给亲完聚。」**
- 「若假以乞养过房为名，买良家子女转卖者，罪亦如之。」
- 和同相诱（自愿）减一等，未卖再减；**「十岁以下，虽和，亦同略诱法。」**
- 略卖他人奴婢减一等；卖自己子孙弟妹侄等按亲疏定罪；**窝主及知情买者同罪，牙保减一等，价钱入官；不知者不坐，价钱给主。**

→ 设计含义（【抽象】）：
- 拐卖有**两条路径**：设方略（有人图谋——街市、庙会、渡口的生人搭讪）和乞养过房（借名——家里穷，有人来「抱养」）。第二条比第一条更贴近明代农家的真实风险。
- 十岁以下无所谓「自愿跟着走」——律文替设计定了一条线。
- 「被略之人不坐，给亲完聚」说明**找回是制度承认的可能**，不是只有 bad end。
- 「牙保」「知情买者」说明这是一条**链**，不是一个人。找回的路可以从链上任何一环开始。
- 风险不是一个概率，是家庭 × 年龄 × 有没有人看着 × 街市 × 同行者 × 生人接触 × 治安 × **有没有人认得这孩子**。最后一项就是邻里那一层的用处之一。

### 6.2 盗与劫 【史料·待核原文】《大明律》强盗（不分首从皆斩）、窃盗（计赃）。乡村守夜；万历朝保甲渐行【推断】。库里 `banditry`/`order` 已有。

### 6.3 讼 【史料·待核 + 书目】户婚田土先经里老人，再赴县；讼师（明律禁「教唆词讼」）；打官司要钱、要中人。**打官司本身是一种人生事件**，库里没有。

### 6.4 灾与疫 【史料·通识】荒政：蠲免、赈济、粥厂、平粜（库里 `price-cap` 对应）；瘟疫。库里已有。

### 6.5 役 【史料·待核原文】里甲正役（轮到那年）、均徭；军户勾补（逃军补丁）；驿递。库里没有。**一个民户人家轮到里长那年，是一件大事**——催不上粮要自己赔。

### 现状与第一个使用者

- 世界事件里有灾、疫、盗、流民，**没有拐卖、讼、役**。三者里拐卖有最硬的史料、用户点名、且已有一个天然的落点（`day:town` 的一个 turnout）——**先写那一个 turnout**，让它逼出「谁认得这孩子」「同行者」「街市拥挤」这几格。

**一条原则，用户 2026-09-06 立的：NPC 不拥有「好人／坏人」标签作为行为脚本；它拥有利益、关系、习惯、记忆和处境，行为从这些里产生。**

那个嗓门大的邻居不是 `event = loud_neighbor`，是这个人本身嗓门大、爱议论、脾气急——于是玩家路过时自然可能听见「隔壁王家的声音又传过来了，隔着两堵墙都听得清」。有时候他帮忙，有时候他惹人嫌，有时候他说了不该说的话，有时候他只是骂自家孩子。**同一个人不该因为「生成成坏邻居」，以后每次出现都做坏事。** 好邻居、坏邻居、世交、世仇、债主、骗子、商人、亲戚、陌生人——都不是固定角色模板，是「人的特征 + 人与人的关系 + 所处环境 + 当下利益 + 机会 → 行为」。

第二条和它同源，也和 README 硬规则五、六、七同源：**用行为积累人格，不用人格数值解释行为。** 玩家不该读到「此人性格恶劣」，该读到「借他的扁担两个月没还」「井边碰见只是冷冷看一眼」「去年办丧事他没来」。库里 `history` + `known.note` 已经是这个形状——**别加「善良 73」那种格，也别让 `temper` 变成面板**。`temper` 眼下零读者，它要么找到第一个读者（脾气决定他借不借你东西），要么删。

## 十一、年号与王朝史（已建，2026-09-06）

**建在哪**：规则 `engine/dynasty.ts`，词库 `content/eras.ts`（七十二个），世界层 `stores/world.ts`（立基时生成、崩时记编年、`eraOf`）、标题 `engine/describe.ts`、占位 `{era}` `{bornEra}`、效果 `{ type: 'succession' }`、门禁 `scripts/dynasty.ts`。存档版本升到 4。

**建的时候定下的两件事**：宫里那一支的父亲 `death` 留空，由 `royal.ts` 的「父皇大行」那一笔填；到十六岁那卷窗口过了还没崩，世界替他定剩下的日子。词库从三十八扩到七十二——三百多年的王朝二三十位皇帝，三十八个偶尔不够用，走查抓到过重名。

**用户改掉的一件事（2026-09-06）**：头一版「剩下的日子」是抽一到二十年——那是一个没有依据的随机分布，几年之后会露出游戏数学。现在**皇帝先是一个人**：`Reign.born` 记生年，几岁即位、活到几岁照明代十五帝的寿数抽，在位年数是差，不单独抽；继任者是儿子（小先帝十八到三十岁）或同辈（小一到十五岁）。宫里那位父亲剩几年，也是问他此刻几岁、还能活多久推出来的——四十二岁即位、在位十四年、今年五十六，抽到寿数六十三，就还剩七年。这一条对「宫里与王府分开」那一卷要紧：宫廷里的人不该只是一个在位年数。

### 第一个使用者：三处已在等（建之前的状态，留作出处）

1. 每一节标题 `describeTime` 印的是「人间 · 第十六年 · 三月初七」。**一个明代人不会这么说时间。** 这是界面上出现最频繁的一行字，也是最像「顶部 UI 标签」的一行。
2. `royal.ts`「父皇大行。你的一位兄长即了位。」——皇帝更替眼下是 `court` 那一支的**私事**：世界层不知道换了皇帝，别的出身的人生里这件事根本不存在。它本该是一件世界事件，所有人都会听说「先帝崩了」「明年改元」。
3. `ChronicleEntry.time` 记的是绝对年，编年史印出来也是绝对年。

### 规则（用户 2026-09-06 定）

> 皇帝生涯随机 + 改元时机随机 + 年号文本随机；**制度、频率、时序、纪年方式必须符合时代逻辑。**

- 架空王朝。**不**把真实年号拿来随机，也**不**用某个真实皇帝做时间轴。
- 内部保留 `world.time.year` 绝对年——年号是它**上面**的一层，不替换它。所有判定照旧读绝对年。
- 生成的不是一串年号，是一段**王朝史**：建立 → 皇帝即位 → 在位若干年 → 改元 → 崩／禅／废 → 下一任。每位皇帝有 `reignStart / reignEnd / eraName / eraStart / eraEnd / reason`。

### 制度约束 【史料·待核原文，《明史·本纪》《明实录》改元诏】【推断】

- **一帝一元。** 明制自洪武起一帝一元（英宗正统／天顺是复辟造成的例外）。
- **逾年改元。** 皇帝崩那年仍用旧年号，次年正月改元——「景和十二年冬，先帝崩，皇太子即位，诏明年改元承宁」，于是「景和十二年」之后是「承宁元年」。用户举的隆庆→万历正是这样。
- **在位年数不是均匀的。** 明代实际：31 / 4 / 22 / 1 / 10 / 14 / 8 / 8 / 23 / 18 / 16 / 45 / 6 / 48 / 一月 / 7 / 17——中位十几年，长尾到四十多年，也有不满一年的。泰昌那种「年号定了人没了」的极短情形要允许存在，但极稀。
- **往前生成。** 王朝史至少要覆盖玩家出生前七八十年——「你出生那年还是景宁」「那是承和年间的事了」得有东西可指。`seedHistory` 现在只往前跑一年，不够。

### 年号文本

- **人工筛选的词库，不是任意两字组合。** 每个词标 style（平和／中兴／肃穆……）和 confidence。明代式审美：承 景 永 隆 嘉 德 弘 正 泰 成 宣 康 和 宁 安 庆 绍 启 顺 熹 崇 治 化 统。不出「永恒」「无敌」「修仙」「天帝」这类字。
- 【抽象·本文作者的假设】**排除真实明代年号原文**（以及唐宋那几个太出名的），免得读成换皮明朝。用户举的例子里有「隆庆」「宣德」两个真年号——若要允许它们出现，说一声。
- 京城名跟着这一条一起换（一、审查表）。

### 落到哪儿

| 谁 | 怎么说时间 |
| --- | --- |
| 节标题、编年、日录 | 「景和十二年 · 三月初七」 |
| 官府文书 | 「某年某月某日」 |
| 读书人 | 「景和年间」 |
| 普通人 | 「旱得厉害那一年」「你出生那年还是景宁」 |
| 老人 | 改元以后仍说「那是承和年间的事了」——**旧年号进入记忆，不因改元消失** |

年号进人物的 `history`、进编年、进对话，**不是顶部标签**。这和「世界事实 → 玩家认知」那套完全契合：年号是世界真实发生过的东西。

皇帝更替成为一件**世界事件**，所有出身都听得见；`court`／`manor` 两支的「父皇大行」「削爵」从它上面长出来，而不是自带一个皇帝。

### 不做

- 不做朝政模拟。皇帝只有生涯和年号，没有属性，不上朝。
- 不一次做「禅位／被废／复辟」全套——先只做「崩 → 太子即位 → 逾年改元」这一条。被废、复辟、幼主等，等 `royal.ts` 或别的内容真要写到再加（先有使用者）。

## 结语：这份文档不做什么

它不画「人—家庭—地域—身份—物质—关系—风险」那张十三层的图然后逐层建格子。**那张图是对的，但它是终点的形状，不是施工顺序。** 施工顺序由审查表里「第一个使用者已在等」的那几处决定：

1. 邻居（有名有姓的几个人 + 一条「邻」边）——正文已经在等。
2. 地域三层（府／县；城／镇／村；脚下那一处）——五处「邻村」、六处「邻县」、人人可点的「去镇上」在等。
3. 宫里与王府分开——`royal.ts` 两卷在等。
4. ~~年号与王朝史~~——**已建**（2026-09-06，第十一节）。
5. `office` 拆官／役、`escort` 改护送——**已定**，属改代码，下一轮。
6. 拐卖那一个 turnout——史料最硬，天然落点已有。

其余各层：先写一卷内容，再回来看它逼出了什么。

**下一步不是写更多明代内容，也不是建代码**：先拿这份底座做一次「社会事实 → 游戏模型」映射，见 `design/society-mapping.md`。每一个历史事实先问一句——**它在游戏里究竟起什么作用**——问不出来的不进模型。
