## 一、修士杀人：两套秩序并存，不做二元切换

### 定下来的那句话

> **世俗律法与修士内部秩序并存，不做「一切修士犯罪自动归修士法」的二元切换。**
> 实际结果由地点、身份、所属、见证、发现与控制力共同决定。
> **修士没有默认「杀凡人合法」的规则。**

### 为什么不做成两张法典

用户的原话：

> 这样会非常游戏化。……「杀了人」这个事实只有一个，
> 但**谁来管、能不能管、愿不愿管**完全可能不同。

一个炼气修士在县城杀死一个平民，三边可以同时存在：

```
世俗官府    杀人案件
宗门        门下弟子惹事
地方乡民    只知道「那个外乡人杀了人」
```

而官府**是否知道他是修士、是否敢抓、能不能抓，是另一回事**。

### 判定由六样共同决定，不是一个开关

```
事件发生地点
→ 当前掌权者
→ 人物所属
→ 受害者所属
→ 是否有人报案／见证
→ 施暴者是否暴露
```

实例（用户列的）：

```
县城里杀人        地方官府更可能介入
深山里杀人        可能没人知道
宗门内部          宗门处理
两名修士之间      宗门／师门／同道规则，也可能直接私仇
杀了别宗门的人    突然变成宗门冲突
杀了王府的人      政治影响又不同
```

### 这一条为什么要紧

> 否则你的世界会直接变成：**修士 = 超然贵族。**
> 这和你一直追求的真实感不一定一致，而且**会让凡人社会失去自主性**。

⚠️ **所以不许出现 `if (isCultivator) skipMortalLaw()` 这种形状。**
「修士」不是一个豁免标记，它只是「谁管得到他」这个问题里的一个变量。

## 二、长生：突破凡人尺度，不等于不死

### 定下来的那句话

> **长生 = 突破凡人自然寿命尺度，并能够持续延续生命；不等于不死。**

不是「达到某境界 = 永远不死」，更不是「一旦修仙 = 自动几百岁」。

### 三层，先后出现，不要求所有修士一路获得

```
延寿    寿命上限增加            某人活到一百二十岁，但明显衰老
不老    衰老速度发生显著改变    某人活了两百年，外表长期停在某个年龄段
长生    不再受凡人寿命尺度支配  某修士数百年仍然继续生活
```

**三者不等价，也不是一条自动的阶梯。**

### ⚠️ 不许填表

用户明确反对：

```
筑基 = 150 岁
金丹 = 500 岁
元婴 = 1000 岁
```

### 长生者照样会死

```
被杀 · 被毁道基 · 重伤 · 走火入魔 · 寿元耗尽 · 因特殊代价死亡
```

> 否则你的 32.md 会退化成：活几百年之后触发八个「你终于长生了」的剧情。

## 三、32.md 要重新分，而这一条改变了那八节的做法

### 不是「长生者专属剧情」，是「寿命变长之后产生的现实结果」

用户的原话：

> 真正有意义的不是「第三百年，你突然发现世界变了」，
> 而是「**你二十岁时认识的人，很多已经不在了**」。
> 这其实只需要几十年。

而这个世界的终年 p50 = 62（实测 600 世，90 岁以上 0 人）。所以**只要修士
真正突破凡人尺度，五十年就够**：

```
童年伙伴都老了
侄孙已经成为老人
认识的官员家族换了几代
原来的店换了主人
老屋变成别人的宅子
记得的人名只存在于族谱和坟墓里
新一代根本不认识你
```

**这才是长生进入凡人社会关系后的效果，而不是「寿命 +1000」。**

### 长生是一种社会事实，不是角色属性

```
她活了两百年

玩家     我认识过她的祖母，现在又认识她
别人     这个人怎么看起来这么年轻

有人知道她是修士
有人只觉得她保养得好
有人怀疑她不老
有人已经确定她不是凡人
```

**这跟三层认知模型（世界事实 / 玩家认知 / 别人的认知）完美接上**，
也跟 22 刚做的 `he-does-not-age`（不老是征象，读错是常态）是同一条。

## 四、这一条同时解掉了 29.md「上山后三十一年全空」

```
→ 师门关系

→ 初次延寿
→ 第一次意识到自己和凡人的时间不一样
```

## 五、用户指定的下一步：先测，别填

> 这两个决定确定以后，我反而建议你**不要马上去填 29～32 的剩余内容**。
> 先做一件非常重要的事：**重新测一次修士出现后的生命周期。**

要测的不是「修士有多强」，是这七个节点各自落在几岁：

```
① 凡人年龄分布
② 第一次接触修士
③ 第一次修炼
④ 第一次明显延寿
⑤ 第一次超过凡人平均死亡年龄
⑥ 第一次出现「认识的人已经死了」
⑦ 第一次真正进入长生尺度
```

> 一旦这个分布出来，你就会知道 29～32 后面的八节究竟分别落在
> 哪个真实生命周期节点。**现在这比继续照着 32.md 的标题写剧情重要得多。**

而这**正好是从「凡人社会模拟」进入「修仙社会模拟」的真正分界线**。
