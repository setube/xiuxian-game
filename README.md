# 会呼吸的修仙

一款纯文字修仙游戏。**纯文字，但仍然是一款游戏** —— 丹青水墨只是视觉风格，
不能压过交互、信息层级和游戏功能。

最终目标是：从一个什么都不会的凡人开始，在充满不确定性的世界里寻找踏入修仙界的机会。
**凡人阶段是起点，不是终点。**

当前版本实现的是这条路的第一段：**出生 → 幼年 → 启蒙 → 少年 → 第一次见到修士 → 打听门路**。
最后那一步绝大多数人走不完——玩十世的人里，多半连门口都没见过。

```text
┌──────────────────────────────────────────────┐
│ 云州 · 临江府 · 柳溪村     第八年 · 三月初七 │   ← 状态栏：常驻，时/地一变就闪朱砂
├──────────────────────────────────────────────┤
│  这一年村里几个同龄的孩子开始去私塾了。      │
│  你听见母亲和父亲在灶间说话，说的是束脩。    │   ← 当前经历：整屏唯一会滚动的区域
│                 ─────                       │
│  你可以：                                    │
│  ○ 每天早去一个时辰   耗 一年   天不亮就出门 │   ← 操作区：可用 / 锁定 / 隐去 三态
│  ○ 跟大家一样上下学   耗 一年                │      时间代价写在落笔之前
├──────────────────────────────────────────────┤
│ 人物 行囊 知识 人际 日录 编年 世界       │   ← 面板栏：有新内容的那一格点朱砂
└──────────────────────────────────────────────┘
```

## 运行

```bash
pnpm install
pnpm dev              # http://localhost:5173
pnpm build            # vue-tsc --build && vite build
pnpm lint             # eslint .
pnpm format           # prettier --write

npx vite-node scripts/simulate.ts   # 随机跑一千世，看人生是否走得通
npx vite-node scripts/verify.ts     # 五道结构门禁（失败以非零码退出）
npx vite-node scripts/grasp.ts      # 认知三轴门禁
```

无后端、无环境变量、无网络请求。进度存在 `localStorage`，刷新即续上一局。

## 已建成的世界基础层

内容可以慢慢加，这一层不能事后补。它们按依赖顺序建起来，
每一层都由 `scripts/` 下的走查守着：

```text
世界基础层
├─ 人物认知系统        玩家读到的是自述与他人之言，不是数值
├─ 第三方观察系统      真实属性 → 观察能力 → 措辞 → 玩家理解，每步都可能失真
├─ NPC 实体系统        持续存在的人，不是一次性剧情变量
├─ 关系图系统          关系是边，不是槽位
├─ 持续关系生命周期    关系会结束，但不会被删除
├─ 出生境况系统        出生 → 生存环境 → 抚养关系 → 人际网络 → 人生发展
├─ 世界时钟            世界先于玩家存在，且玩家不在场时照样在走
├─ 感知系统            世界状态 → 玩家可观察到的现实（可能读错）
├─ 打听系统            主动去问，得到的是那个人的局部世界
├─ 认知三轴            接触只能往上，解释可以往下，对错与两者正交
├─ 认知扰动            动摇 / 有了别的说法 / 明确纠正，三种各不相同
├─ 主动行动            没有人叫他，他自己决定今天干什么
├─ 日录　　            我活过什么。旧日子可以被后来的事重新点亮
├─ 念头　　            经历 → 倾向 → 反复 → 说得出口。大多数人说不出口
├─ 机会　　            世界照常发生，念头只改他怎么读它
├─ 需求→愿望→念头     三层各管一头，而愿望不必通向任何地方
└─ 找门路　            打听 → 跑一趟 → 门前。假的占大头，而他分不出来
```

### 十二条硬规则

前十一条是设计立场，第十二条是**能跑的验收**——因为它一旦破了，
不会报错，只会让玩家读到自己死去的父亲下地干活。

| #   | 规则                                               |
| --- | -------------------------------------------------- |
| 1   | NPC 必须是持续存在的实体                           |
| 2   | 重要 NPC 不得匿名                                  |
| 3   | 人物关系用图结构，不用固定槽位                     |
| 4   | 关系结束不代表关系历史消失                         |
| 5   | 世界事实与玩家认知严格分离                         |
| 6   | 第三方评价不得修改真实属性                         |
| 7   | 第三方评价不得作为 `Condition`                     |
| 8   | 第三方评价只能通过玩家选择影响人生                 |
| 9   | 出生环境可以极端不同                               |
| 10  | 出生环境不直接决定角色最终上限                     |
| 11  | 世界事件改变条件，不直接替玩家决定结果             |
| 12  | **内容必须适配不同家庭结构，不能默认玩家拥有父母** |

第 12 条的来历值得记下来：关系图做完的当天，走查发现
**227 个「生下来就没爹」的人生里，227 个的正文仍在写「父亲每天傍晚去地里站一会儿」**。

那不是一个内容 bug，是**藏在剧本里的系统假设**——写剧本的人默认了玩家有爹娘。
这种假设不会自己消失，只要还有人往里加正文，它就会重新长出来。
所以它必须是一条跑得起来的验收，而不是文档里的一句话：

```bash
npx vite-node scripts/verify.ts
```

> 任何重要事件，在没有对应关系节点时，都不能产生关系穿帮。

### 五道结构门禁

纯文字游戏最容易坏的地方不是类型错误，是**某条剧情只有千分之一的人生会走到，
所以它坏了半年也没人发现**。`verify.ts` 现在拦五类：

| 门禁     | 拦什么                                        | 当前              |
| -------- | --------------------------------------------- | ----------------- |
| 关系穿帮 | 没爹的人生里正文写「父亲下地干活」            | 300 世无穿帮      |
| 断头路   | 跳转指向不存在的节点（id 是字符串，tsc 不管） | 61 卷 295 条      |
| 孤儿     | 忘了删的旧节点，和忘了接入口的整卷            | 254 个 · 61 卷    |
| 前置条件 | 剧本要一样东西，而世上根本没人给              | 37 种都有出处     |
| 可观测   | 图上连得好好的，人生里却没人抵达得了          | 300 世走到 89–93% |

第四道起因是一次真的回归：把 `omen:wounded` 改成五节点时，
六个旧结局节点被删了，挂在它们身上的 `thin-book` 和 `touched-by-wicked` 一起没了。
**正文照样在说「他从怀里摸出一册薄书，塞进你手里」，行囊里却是空的**，
而十六岁渡口认得这册书的那个结局，就那么哑了。前三道都查不到它——
节点连得好好的，断的是前置条件。

#### 而第五道是另一层：来源和路径会分开坏

同一轮里撞见两件事，看着像同一类，其实分属两层：

```text
illness-at-home     火种引用了它，世上没有一处设过它      → 来源问题
omen:wounded#miss   节点连得好好的，三百世零个人走到      → 路径问题
```

于是这一句正式改成：

> **门禁检查所有内容元素是否有「来源」和「可观测路径」。**

**一个事件存在，不代表玩家有机会经历它。** 普通事件表查的是「事件有没有触发」，
这一道查的是「这个人的人生轨迹是否可能抵达那儿」。

它不能要求「每个节点都有人走到」——那条要求会逼着把长尾内容删掉。
所以它只把没人走到的名单**印出来**，给人读，不给人清零，
读法是去可达性那一层查它。头一批跑出来就分出了两种截然不同的东西：

| 名单成员                     | 查下来是什么                               |
| ---------------------------- | ------------------------------------------ |
| `seek:crossed` / `seek:door` | **稀**。每一环都在乘，三百世期望一个人上下 |
| `routine:adult`              | **零，而且证得出永远是零**                 |

前者的交代在 `scripts/seeking.ts` 第七节：两千世完整人生，走进去七回上下。
链条完好，只是「心里生出想弄明白」4% × 「听说过有修士」37% × 「年表抽中问人那一卷」3%
× 「真问着了东西」2% × 「两条消息撞在一处」千分之几——乘到最后三百世轮不到一个人。
**一个期望值在一附近的格子印出零来不是内容坏了，是三百世不够。**

> 那一节还顺带查出一件本来看不见的事：「两条对上了」的人绝大多数是**十五岁那年**
> 才对上的，而用得上它的那一卷窗口是十三到十六。这条路十有八九只赶得上最后一年——
> **旗标设上的时候，那扇窗快关了。** 它现在还通，可再往前挪一岁就会当场断掉，
> 而断掉的样子跟今天一模一样：名单上多两卷，谁也说不清为什么。

后者是另一回事。`riverman` 事件 `window: 16–99`、`weight: 1000`，十六岁必被抽中，
演完就 `finish()`；而 `stageOf` 里十六岁仍算「少年」，十七岁才「成年」。
**人生在十六岁那年的渡口上结束，而成年要到十七岁才开始——中间那一年谁也活不到。**
不是漏接，是这一段人生还没写。留着它替将来占位子，原委写在那一卷上头。

#### 而这一道差点变成一支会随机红灯的门禁

第五道原本还兼一件事：守住那份名单别越来越长，上限 32。
理由听着挺硬——**新加一卷却忘了接入口，名单该多出五到十个，必须顶穿它。**

后来把三百世那一批跑了十二遍：

```text
16　21　19　22　20　21　22　24　28　30　37　19
均值 23.3　标准差 5.6
```

**十二批里有一批 37。** 上限 32 大约十二分之一的概率会红一次，
而红的原因是抽样、不是内容——那正是这一整套走查最忌讳的事。

晃成这样是因为这份名单不按「个」跳，按「卷」跳：`seek:crossed`
十二批里有五批整卷没人走到，`royal:fall` 三批，`birth:皇室` 一批。
一卷稀，它就整卷进进出出。**噪声幅度 ±11，而要抓的信号只有五到十个节点。**

于是那件事整个挪走了。一卷只有三种进法——年表事件、四个阶段的日常、
收尾那一卷，外加别卷跳过来；`begin()` 也只是 `toNextChapter(0)`，
连出生那一卷都是年表抽出来的。**所以「这一卷有没有入边」是纯静态的，
一个随机数也不用掷**，现在归第三道。第五道剩下的上限改成 40
（均值加三个标准差），只防一件事：一次改动把大片内容切下线。

> **能静态判的，别拿模拟去判。** 模拟是用来量分布的，不是用来判存在的——
> 判存在，抽样迟早会替你判错。

### 写新剧本时

- 正文里的长辈写 `{elder}`（管家的大人）、`{dam}`（娘这个位置）、`{elders}`（合称），
  落纸时由关系网决定那是谁。
- **`{elder}` 是过渡方案，不是地基。** 它只解决「谁在做这件事」，
  解决不了「他为什么会做这件事」——老乞丐、长姐、寺里的师父、亲爹，
  不可能共享同一套生活内容。「每天傍晚去地里站一会儿」换个主语仍然是错的，
  因为讨饭的人没有地。
- 所以：**只写谁都可能做的事**（`{elder}每天傍晚都会出去一趟`）；
  真要写只有某种人才做的事，就给那一卷加 `requires: [{ bond: { kind: '生父', alive: true } }]`
  把关系锁住，然后正文里放心写「父亲」。

## 不做成开局词条抽卡

「十六岁随机抽一个背景【家破人亡】【家道中落】【获得机缘】」是这类游戏最容易滑进去的坑。
本作反过来做：**玩家不选出身，也看不到有得选。** 引擎幕后按权重掷定，
游戏第一句话就是既成事实——「你生在柳溪村，家里有六亩薄田。」

出身共十一种，权重照着真实的社会结构配：种地的占四成，皇子百里挑一。

**州府和出身是分开掷的。** 从前地名写死在出身里（`'云州 · 临江府 · 柳溪村'`），
于是所有人都挤在同一个府。现在一条大江贯穿四州十府，沿岸设治，
出身只管到街巷村名这一级，两边组合——
一个农家子可能生在江陵府的杏花坞，也可能生在东莱府的下河屯。
一共 **532 种不重样的门牌**（那是三段名字的笛卡尔积，算出来的），
六千世抽到其中 524 种，临江府只占 14.1%。

「沿江设府」不是装饰性的设定，是一条硬约束：收尾那一卷靠「渡口」和「江面」立住，
所以每个府都必须临水。古时设府本来也多在漕运要冲上，这一条既省事又不假。

| 出身 | 占比 | 这一家的孩子会遇到谁                               |
| ---- | ---- | -------------------------------------------------- |
| 农户 | 38%  | 天时、收成、一条可能走完也可能断掉的父债链         |
| 猎户 | 11%  | 从小进山。他比谁都容易在山道上看见路边的人         |
| 匠户 | 10%  | 木头味、刨花、分得出松和杉                         |
| 商户 | 9%   | 铺子里的外乡人。走北路的商旅在檐下说起过修士       |
| 客栈 | 8%   | 南来北往的人。有一夜来了个下雨不湿的客人           |
| 酒楼 | 7%   | 喝多了的人什么都说。有个跑山的说他见过脚不沾地的人 |
| 药铺 | 6%   | 八岁认得三十味药。有一天来了一味谁也认不出的       |
| 镖局 | 5%   | 父亲身上的刀口，和舆图上被朱笔圈掉的那几条道       |
| 官宦 | 3%   | 父亲对着别人弯腰。衙门里有一桩不许记档的案子       |
| 王府 | 2%   | 很高的墙。墙外有孩子在跑，你只听得见               |
| 皇室 | 1%   | 所有人都跪着。而钦天监那道门，你每天经过           |

**稀有出身不是「更好的开局」。** 皇子识字最多、家底最厚，
可他「知道有修士」只有 26%——酒楼伙计的儿子是 81%。宫墙替他挡住了所有的苦，
也替他挡住了所有的机缘。他不会在山道上救人，不会蹲在货郎摊前翻旧纸。
八品官的儿子和农户的儿子站在渡口，青衫人看他们的眼神是一样的。

「家道中落」也不是一个词条，是连着好几年长出来的一串事：

```text
连年雨水不足 → 收成不佳 → 父亲欠下一笔债 → 父亲为还债离开家乡
→ 死在外地 / 再无音信 / 几年后回来
→ 家里少个劳力 → 你不能再读书 → 你识字一般，但比同龄人壮实
```

每一环都靠上一环留下的旗标才进得来。中间任何一环条件没凑上，这条链就断在那里——
一千次模拟里，它只走完了约四十次。**一个人的一生里，它本来就常常不会走完。**

宗室另有一条：夺嫡、削藩、抄家。约四成的宗室会在十三到十五岁之间失去一切，
然后以一个什么也不是的人的身份，站到渡口上。剩下六成不会——
他们十六岁那年也在江边，只是身后跟着两个人，连走上前都要先想办法把人支开。

## 世界先于玩家存在

世界从第一年就开始跑了，玩家生在第几年是掷出来的——
**两个玩家进入的是同一个世界，只是人生起点不同。**
走查里，玩家出生时这个府平均已经有十六年历史，而那些年跟他毫无关系。

年龄因此不再是 `year - 1`，而是 `year - bornYear`。

### 灾难是连锁，不是戏剧性

世界事件只做一件事：**改条件**。它绝不替玩家决定结果。

```text
少雨 → 减产 → 米价涨 → 有人囤粮 → 官府限价 → 米铺关门
     → 路上不太平 → 商队改道 → 有人往南边逃荒
```

每一环都要**前一环发生过**才轮得到。链条上任何一处没凑上，后面就不会发生。
跑一百年的结果：少雨 6 次、减产 2 次、涨价 3 次、囤粮 2 次、限价 2 次、
盗匪 1 次、改道 1 次、逃荒 0 次——**一路收窄**。

而且 **59/100 年什么也没发生**。这一条是刻意的：世界不该是灾难流水线，
大部分年头平到没人会记进编年史。不是每个人都活在故事的中心。

### 验收：同一场旱灾，长出不同的人生

要看的不是「有多少人遭遇旱灾」，而是同一个「米价涨了」落在不同的家里
会长出什么。走查（`scripts/world.ts`）：

| 出身 | 同一场旱灾里的走向                              |
| ---- | ----------------------------------------------- |
| 农户 | 紧一年 22　**有得选 9**　**饿过 2**　照常开饭 1 |
| 猎户 | 紧一年 12　有得选 1　照常开饭 1                 |
| 商户 | 照常开饭 10　紧一年 2                           |
| 皇室 | 照常开饭 1                                      |

农户是唯一会走到「饿过」那一档的；商户以上根本碰不到。
而「有得选」那一档里，玩家还要自己挑：卖东西、借债、还是让孩子出去做工——
**世界把条件推到这里，然后闭嘴。**

## 玩家怎么看世界

跟观察系统是同一个立场的两面：那边是**别人怎么看你**，
这边是**你怎么看世界**。两边都不给数字，都可能失真，都要玩家自己拼。

> 不是隐藏数值，而是让玩家通过文字建立自己的世界模型。

玩家永远看不到 `grain = 162`。同一场旱灾，七种人看见七样东西：

| 谁             | 他看见什么                                 |
| -------------- | ------------------------------------------ |
| 农户           | 入夏之后没下过透雨。地里裂了缝。           |
| 猎户           | 山泉细了。今年的兽也比往年瘦。             |
| 商户           | 进货的路不好走了。铺子里的货卖一件少一件。 |
| 客栈           | 店里空了。住进来的多是给不出房钱的。       |
| 镖局           | 局里的活多了。走一趟的价钱涨了一倍。       |
| 药铺           | 抓药的人从早排到晚。有几味药早就没了。     |
| 紧巴人家的孩子 | 这阵子的粥稀了。                           |

### 三条性质，缺一不可

1. **不是人人都看得见。** 农户看得出今年雨水不对，城里孩子看不出。
2. **看不全。** 一年只给一两处——给全了，玩家就能反推出精确的世界状态，
   那跟把数值摊开没区别。走查里同一个农户同一年跑四百次，
   每一处的出现率都在 17%–47% 之间，**没有一次能看全**。
3. **可能读错。** 这一条最要紧：

```text
「村口这阵子常有陌生人过。」
  └ 你以为是过路的客商。          ← 寻常人

「村口这阵子常有陌生人过，拖家带口，走得很慢。」
  └ 那是逃荒的。                  ← 心思细的人（insight ≥ 52）
```

同一个事实，两种世界模型。**玩家建立的模型可以是错的**，
而且他多半永远不会知道自己读错了。

### 一个农家孩子的十六年

```text
 1岁  入夏之后没下过透雨。地里裂了缝。
 2岁  秋后打下来的粮，装不满往年的仓。
 3岁  爹跟人说话时提过两回米价。
        └ 你听见了，但没往心里去。
 4岁  雨水还算匀。地里的活跟往年一样多。
 ……
13岁  今年是个好年景。场院上晒得满满的。
```

他经历了一场旱灾的头三年，然后世道缓过来了。
**他从没听说过「旱灾」这两个字。** 他只是记得有几年粥很稀。

## 玩家主动去问

前一层（感知）是世界给他看的，这一层是他自己去要的。
但要来的**不是正确答案，是那个人的局部世界**。

同一个「今年年景如何」，问四个人：

```text
爹：是贵了些。家里省着点吃。
同村的老人：想了半天，说他也不晓得。
米铺的掌柜：含混地应了一声，没有往下说。
衙门口的差役：本月米价仍在官府限价之内。
  └ 你想起街口那家米铺已经三天没开门了。
```

**四句话都不假，四句话拼不出真相。** 他得自己判断信谁，而且可能判断错。

### 两道闸：知道 ≠ 肯说

拆成两个独立的数，才能表达「他知道，但他不告诉你」——
而那恰恰是玩家最常撞上的情况：

| 谁         | 知道 | 肯说 | 真问出来的 |
| ---------- | ---- | ---- | ---------- |
| 米铺掌柜   | 88   | 22   | **20%**    |
| 家里的大人 | 95   | 40   | 37%        |
| 村里的老人 | 66   | 88   | 59%        |

掌柜知道得最清楚，却最问不出来——那是他的生意，他不会跟一个孩子交底。
而「他含混地应了一声」这句本身就是信息：**他知道，只是不肯说。**

玩家能问出什么还受年纪、关系、见识影响。十岁的孩子问衙门口的差役，
跟十六岁的伙计去问，得到的不是一回事。

### 玩家开始自己提问题

从前的循环是「事件找上门 → 给三个选项 → 挑一个」。
现在是「你看见了什么 → 你自己觉得不对劲 → 你决定去问谁」。

所以打听那一卷永远留着「接着干活去」——**什么都不问也是一种选择。**

## 知道不是一个开关

```text
听说 → 见过 → 猜想 → 确信 → 亲历
```

而且**只能往上走**。亲眼见过修士之后，再听人说一嘴，
不会退回「只是听说」。

同一个条目在不同的档位上，说法完全不同——升档不是补充细节，是**换一句话**：

```text
〔听说〕有人说这世上有能飞的人。多半是编的。
〔见过〕你亲眼见过一个。他站在船头，水面不动。
〔猜想〕他们大概是修行了什么法门。
```

这一层是后面「为什么拿到功法却不会修炼」的地基：
他手里那册书是真的，可他对「炼气」还停在「听说」——
中间那几档没走完，书就只是纸。

## 我今天想做什么

到这一步为止，玩家所有的行为都是**被事件叫出来的**：年表挑中一卷，
他在里面做选择。`day:ordinary` 反过来——没有人叫他，**他自己决定今天干什么。**

一天分三段，每段自己挑一个去处：

```text
【上午】帮家里干活
    今天出的力比往常多。
    晚上躺下的时候，腰是酸的。

【下午】去镇上
    庙前有人摆摊，卖的是针头线脑。
    你蹲着看了一会儿，什么也没买。
    摊主没赶你。

【傍晚】找爹说话
    爹在忙自己的事，没顾上你。
    你在旁边坐了一会儿，起身走了。
```

### 大多数行动没有机缘

这一册最要紧的一条规矩，是它**绝大部分内容都什么也不发生**。

每次行动都给知识、给属性、给新人物、给奖励，那是操作游戏，不是人生。
两千次行动的形状（`scripts/day.ts`）：

| 档   | 占比       | 是什么                           |
| ---- | ---------- | -------------------------------- |
| 无事 | **约 77%** | 什么也没发生                     |
| 处境 | 约 15%     | 手上多个泡、跟谁近了一点         |
| 见闻 | 约 5%      | 问出了什么、看见了什么、认识了谁 |
| 转折 | 约 2%      | 这一天真的改了后面的路           |
| 大事 | 约 0.4%    | 撞上了一件事，这一天整个被它占了 |

一路收窄，而且这**不是配平，是立场**：一生中绝大多数日子本来就什么也没发生，
也正因为如此，真的改变了什么的那些日子才显得要紧。

走查把「越往下越少」做成了硬验收——哪一档翻上去，非零退出。
**空的那一档也要拦**：「大事」占不到半个点，四百次里期望两三次，
三批里有两批是 0.0%——而「一档比一档少」那把尺子对 0 静默放行。
**没抽到和最少的，在那把尺子下长得一模一样。** 现在先查在不在，再查形状。

### 「无事」不是空白

一句「你干了一上午活」是填充物。这一册里的无事必须做到三件事：

**一、具体。** 不是「干活」，是「割了半晌草，手心磨出个泡」。

**二、带着世界。** 同一块地，旱年和丰年不是一件事：

```text
太平年景　30%  你跟着下了地。
旱灾中段　16%  地是干的。锄头下去，土块碎成面。
               {elder}半天没说话。
```

玩家读的每一句「无事」，同时也是在读这一年的光景。

**三、偶尔留个钩子。**

```text
你回来的时候，看见{elder}站在门口跟一个人说话。
你一走近，他们就不说了。
那人你没见过。他走的时候看了你一眼。
```

机制上什么也没变，可玩家知道有事在发生，只是这一天他没碰上。
**这是「过日子」和「空转」的分界线。**

### 能去哪儿，本身就是处境

去处不是一张固定的菜单：

```text
上着私塾、家里有人管的　上午：干活　去私塾　去镇上　山那边　找人玩　待在家　什么也不做
                        傍晚：找娘说话　待在家里　什么也不做
没上过学的　　　　　　　上午：干活　去镇上　山那边　找人玩　待在家　什么也不做
没有人管的　　　　　　　傍晚：待在家里　什么也不做
```

没上私塾的人没有「去私塾」，没人管的孩子没有「找人说话」。
**这不是锁选项，是他本来就没有那个去处。**

### 机缘不是年表发下来的，是他自己走过去的

| 他去了哪儿   | 可能撞上什么           |
| ------------ | ---------------------- |
| 往山那边走走 | 山道上那个人 约 4.4%   |
| 去镇上       | 货郎摊上那册书 约 3.5% |
| 帮家里干活   | 什么也撞不上           |
| 待在家里     | 什么也撞不上           |

撞上了，这一天就整个交给那一卷。于是「机缘」第一次不是从天上掉下来的——
**是他自己抬脚走过去的。**

## 时间过去了，但过去没有消失

一天过完之后，它去了哪里？

如果「无事」读完就消失，那玩家最终只记得那几个转折点，
体验会重新退回「事件集合」。所以有了**日录**——而它跟旁边两格
分工不许混：

```text
日录　我活过什么
认知　我以为那是什么
编年　什么真正成为了人生
```

编年必须稀：一生中值得进去的事不超过几十件。而他活过的日子有几万天，
那些什么也没改变的日子**恰恰是他活过的证据**。

### 光把每天的话存起来，那只是日志

```text
十三岁　今天帮家里收了一下午麦子。
十五岁　今天帮家里收了一下午麦子。
十七岁　今天帮家里收了一下午麦子。
```

单独看一句意义也没有，存三百条还是三百句废话。

真正让一天变成回忆的，是**后来发生的事让它重新有了意义**：

```text
【十岁那年】
    山路上没有人。
    你走到能看见村子的地方就坐下了。
    坐了很久，什么也没想。
    ——这一天什么也没发生。

【十六岁那年，他知道了修士这回事】

再翻回十岁那一天：
    山路上没有人。
    你走到能看见村子的地方就坐下了。
    坐了很久，什么也没想。
    └ 六年后你才知道，那条道上走过的人里，有些不是寻常人。
```

**原文一个字也没改，可这一天已经不是原来那一天了。**

```text
过去的事实　+　现在的新知识　=　新的意义
```

这跟认知系统里「原来那册是写坏的符书」是同一个结构：当年那句话没有变，
变的是他现在怎么看它。所以 `lines` 是当年的原话、永远不改，
后来想明白的只往 `hindsight` 里追加——跟知识条目只往 `history` 里
追加、绝不抹掉旧说法，是同一个立场。

### 两条分寸

**当场就明白的不算。** 每条规则都有 `after`，隔得不够久就不点亮——
这一层的全部价值在于隔了很久。走查里当天知道修士点亮 0 天，
四年后回头看点亮 1 天。

**不是每一天都会被点亮。** 八年的日子塞满所有能拿到的认知，
最后只有 35% 的日子有下文。如果每一条日录最后都被点亮，
那这套东西只是把「发奖」延后了。

### 而某件天天做的事，从某年起再也没有出现过

```text
你十四岁以后，再也没有替家里下过地。
```

这一句是**算出来的，不存**——它的真假取决于回看的那一刻。
存下来的那一刻它就会开始说谎：他明天又去了一趟，这句话就不成立了。

那三百句「今天帮家里收了一下午麦子」，到这里才变成人生。

### 走查（`scripts/diary.ts`）

前五项验引擎能不能做到，第六项验**它在真实人生里真的发生了吗**：

| 观察项                 | 值      |
| ---------------------- | ------- |
| 走到卷终               | 100%    |
| 每世日录条数           | 中位 27 |
| 有过「多年以后才明白」 | 64%     |
| 有过「再也没有」       | 38%     |

第六项抓到过两个只有跑全人生才看得见的问题：

- **「一天」在年表里一辈子只发生一次。** 于是日录里永远只有孤零零一条，
  「多年以后才明白」根本没机会出现。加了 `repeatable` 才解决——
  大多数人生事件一辈子确实只来一次，但「过日子」不是。
- **`day-omen` 设了不清。** 每一段都会重新跳进同一卷机缘，
  玩家的人生卡在同一个货郎摊前，一年一年地重来。
  症状是收尾落点里冒出了 `morning` 和 `interest`——**人生停在了半路上**。

两个都不是单支走查看得见的东西。**能力成立 ≠ 真的会发生。**

### 已知边界：三百年怎么办

眼下每天全文保留。凡人这一段（十六年、二十来条）完全够用，
但一个活三百年的人会攒下十万条——**这是一个已知边界，不是没想到**。

`DayEntry` 的形状是照着日后能折叠设计的：折的时候把一段时间里的
若干条压成一条摘要，`tags` 取并集，`hindsight` 照旧追加。
这一轮先把「旧日子能被重新点亮」这个闭环验通，压缩留到后面。

## 人为什么会开始想做某件事

到这一步为止，玩家会感知、会误解、会打听、会行动、会失败，
过去也可以被重新理解。但还缺一样东西：

**他为什么会从「活着」逐渐变成「想做某件事」？**

这件事必须做对，否则修仙最终会变成「十六岁自动开始修仙」——
剧情塞给玩家的主线，而不是他人生里长出来的目标。

### 但绝不做成「勇敢 72 / 好奇 81 / 野心 43」

那样人的内心就变成了一张给玩家看的数据库，
而这跟前面几轮反复守住的立场是冲突的：
**别人怎么看你不给数字，世界什么光景不给数字，
那么你自己是什么人更不该给数字。**

所以念头做成跟日录同构的东西：它不是一个数，是**一串他做过的事**。

```text
第 29 年　晚上又陪着坐了一会儿。
第 30 年　又下了一天地。
第 31 年　他头一回把家里的难处跟你说了。那天以后你就没再当自己是孩子。
第 32 年　在家待了一天。
第 34 年　场院上晒得满满的。你站着看了一会儿。
        ……另有 22 件

16 岁：你想把日子过安稳。
```

最后那一句不是系统贴的标签，是上面那一串攒出来的。
**「我好像总是这样做」得让玩家自己读出来。**

### 三个阶段，而中间那一层是关键

```text
埋着　什么也不显示，只在日录里留下痕迹
反复　带某些标记的日子里，正文多出一句
明白　他自己说出来了
```

念头一冒出来就变成「【任务：成为郎中】」，那是任务系统，不是一个人的一生。
真实的样子是这样的——同一个人到了「反复」这一档：

```text
这一天在【山那边】→ 你在能看见远处的地方站了很久才回来。
这一天在【镇上】　→ 回来的路上你走得很慢。
这一天在【在家】　→ 你在门槛上坐着，看的是村口那条道。
```

**没有新选项，没有任务条，只是他本来就会做的事上多了一句话。**
玩家会先觉得这句话眼熟，很久以后才反应过来自己一直在这么干。

### 验收标准不是「多少人获得了目标」

那是任务系统的问法。要看的是**方向的分布形状**（`scripts/leanings.ts`，1000 世）：

| 一生走完     | 占比      |
| ------------ | --------- |
| 始终没有方向 | **55.3%** |
| 有个说不清的 | 26.6%     |
| 说出来了     | 18.1%     |

绝大多数人一辈子没有明确的方向——好好过日子、养家、把孩子拉扯大、
平平安安走完。**那不是失败路线，那是大多数人。**
如果每个人最后都长出一个「我要改变命运」，凡人生活就失去了真实性，
而后来那一句「我要修仙」也就没有分量了。

分档只说了形状，说不了**哪个念头够得着这道线**。所以还要逐个念头看两列
（一个人可以同时动过好几个，所以每列都不必加到 100%）：

| 心里长出来的               | 动过的 | 说出口的 |
| -------------------------- | ------ | -------- |
| 你想把日子过安稳。         | 22.7%  | 8.9%     |
| 你不想再被人按住。         | 12.3%  | 3.7%     |
| 你想弄明白那些说不通的事。 | 7.7%   | 3.4%     |
| 你想让家里过得松快些。     | 5.9%   | 1.3%     |
| 你想活得久一点。           | 5.0%   | 1.0%     |
| 你想离开这里。             | 3.5%   | 1.2%     |
| 你想学看病。               | 1.2%   | 0.8%     |

**门禁守的是「动过的」那一列，不是「说出口的」那一列。**
最稀的「想学看病」说出口只占八个千分点，要它每批都稳定出现得三千世起步——
而这一支一世要走完一辈子。「动过的」那一列样本厚得多，
而一个念头真够不着线的时候，它这一列也会空。**报出来的数字和守住的底线，
本来就不必是同一个。**

「把日子过安稳」占了说出口的人里的 44%——它是七种之一，而且是真正的方向，
不是「没有目标」的委婉说法。

### 两道门槛是量出来的，不是拍脑袋的

头一版两道门槛是猜的，结果 **86.7% 的人都说出了口**——凡人生活整个塌掉。
第二版把 tag 火种加上 `chance` 之后又矫枉过正到 95% 卡在「说不清」。
第三版才去量：一个人最重的那个念头中位在 14、九十分位 17，
于是「反复」定 15、「明白」定 18。**先量分布再定门槛，才收得住。**

`chance` 那一条是长尾真正的发条：没有它，凡是天天做的事都会稳稳往上加，
于是人人都会长出方向。而真实的样子是——同样去地里干活，
绝大多数时候心里什么也没留下，只有偶尔那一次会。

### 门槛是一把尺子，可它量的东西不在一个量级上

后来加了愿望分岔和「找」那几卷，同一批念头被更多的事推着走，
15 就放过了 57% 的人——「绝大多数人一辈子说不出口」这句话悄悄不成立了。
照新分布重定成 **18 / 21** 的时候，底下那个真问题才露出来：

**七个念头压根不在一个量级上。**

那一次不再看总分布，改成逐个念头量它一辈子最高能长到几分：

| 念头           | 从前的天花板 | 够得着 18 吗   |
| -------------- | ------------ | -------------- |
| 想把日子过安稳 | 二十多       | 够             |
| 想弄明白       | 二十上下     | 够             |
| 想离开这里     | 17           | **不够**       |
| 想让家里松快些 | 12           | **不够**       |
| 不想再被人按住 | 7            | **差得没边儿** |

也就是说，「你不想再被人按住。」和「你想让家里过得松快些。」这两句
**从写下来那天起就说不出口**——不是我把门槛提高才害死的，
15 那一版它们同样够不着。**一条谁也够不着的线，跟没写这条内容是一回事。**

原因不在权重，在火种挂在哪儿：

- 「想过安稳」有三条日常挂在最常见的三个标记上（在家 10.6 次/世、家里的大人 8.6、替家里下地 5.4）
- 「想让家里松快些」唯一那条日常挂在「粥稀了」，而那个标记**只在百分之一的人生里出现过**

**火种挂在什么标记上，比它给几分要紧得多。**

补的时候还量出第二件事：**一条日常火种一辈子拢共只攒得下两三分。**
挂满四条也不过十来分，离二十一分那道线差得远——
所以「说出口」那一档实际上是由**一次性的大事**决定的，不是日常攒出来的。
于是每条够不着的线都补了两样：几条挂在常见日子上的日常，
外加一件真发生过的大事（错过的车队、护不住的弟妹）。

眼下七个念头全都够得着：最低的那个（想学看病）有 1.2% 的人生动过它，
0.8% 说得出口。

> 所以门槛改动之后要做的不只是重量分布，**还要逐个念头看它够不够得着这道线。**
> 而逐个看的时候要看「动过的」那一列——「说出口的」最稀处只有八个千分点，
> 一千世里八个人，拿它当门禁会三天两头误报。**判据要落在够厚的那一档上，
> 哪怕报给人看的是另一档。**

### 火种不许自带剧情

38 个火种，它们认的全是**已经发生过的事**：日录标记 19、旗标 10、
知识 8、出身 1。念头必须从人生里长出来，不能是另一套平行的剧本。
权重也都压在 6 以内——**一个人的方向是几十件小事磨出来的，
不是某一天忽然想通的。**

## 念头反过来影响行动，但不替他做决定

念头若只出现在人物面板里，它终究只是一张人物画像。可它一旦直接变成
「【任务：跟商队走】」，这个游戏就换了一种。

正确的位置在中间：**念头改变的是他更容易注意到什么、更愿意试一试什么、
更容易坚持什么——而不是替他做决定。**

### 同一个机会，两个人读到的不一样

```text
【心里什么也没存的人】
    镇上的货栈在招短工，管饭，按天算钱。

【想离开的人】
    镇上的货栈在招短工，管饭，按天算钱。
    你忽然想到，货栈的活是跟着车队走的。
```

同一条告示，**同一组选项**。多出来的那一句不添信息，只添注意力——
「货栈的活是跟着车队走的」是他自己想到的，不是管事的多告诉他的。

### 念头不得创造世界事实

商队本来就要走，短工本来就在招，那条道本来就在那儿。
**世界不因为玩家想要什么而配合他。**

所以机会的入场条件里一个念头也没有（做成了静态门禁）：

| 机会     | 入场条件                         |
| -------- | -------------------------------- |
| hiring   | 年纪 ≥ 12                        |
| caravan  | 年纪 ≥ 13、旗标 `toward-leaving` |
| the-road | 旗标 `saw-the-road`              |

`toward-leaving` 是**玩家自己攒出来的**——他去问过、去做过短工，
管事的才认得他。一个从没动过离乡念头、却恰好来问过两回的人，
到那一天照样会被问一句。**世界认的是脸，不是心思。**

### 四种人生，而「没走成」是大头

`scripts/leaving.ts`，1500 世里 100 世的「想离开」长到过「反复」那一档：

| 人生                       | 占比    |
| -------------------------- | ------- |
| A 越来越主动，最后真的走了 | 3%      |
| **B 一直没动，留在原地**   | **87%** |
| C 念头后来退下去了         | 10%     |
| D 走了一趟，回来改了方向   | 3%      |

**这四个数字读作约数。** 分母是那 100 个动过念头的人，不是 1500——
A 和 D 各只有三个人，多一个少一个就是一个百分点。
1500 世量得住 B 那一档的形状，量不住 A 和 D 的小数位；
要把最稀的一档抬到十来个人得五千世，而这一支一世要走完一辈子。
**门禁要的世数，和一句结论要的世数，本来就不是一回事**——
底下的门禁只查这四档在不在，不查它们各占几成。

B 最要紧：**有一个念头 ≠ 必须实现这个念头。** 否则念头就成了隐藏任务。

### 念头不是一条经验条

八成的人生里，「想离开」被什么东西压下去过。而**压下去的时候，
顶上来的不是空白**：

```text
家里病倒一个人的那阵子，你没有再提过出门的话。
    你想离开这里。 −5 → 你想把日子过安稳。

你留意到他今年比去年瘦。你想的是自己要是不在，谁来管。
    你想离开这里。 −2 → 你想把日子过安稳。

你回来了。路上那两个月，你想起家里的次数比想起别处多。
    你想离开这里。 −8 → 你想把日子过安稳。
```

他没有改主意，他只是走不开——而年复一年地走不开，跟改了主意其实差不多。

这跟认知系统里「解释可以往下掉」是同一个立场：
**玩家对世界的认识会改变，玩家对自己想要什么的认识也会改变。**

为此 `LeaningState` 多了一个 `peak`：念头退回去跟从来没有过是两回事，
**一个想走了三年最后留下来的人，跟一个从没动过这个念头的人不是同一个人。**

### 走查必须模拟人，不能模拟骰子

这一支走查里有一段**刻意不随机**的代码：心里存着「想离开」的人，
读到那句话之后六成半会去点那一条；心里什么也没存的人只有一成半。

这不是作弊——**这套设计的机制本身就是「念头改变他注意到什么，
注意到什么改变他会点哪一条」**。走查若一律随机，就等于假设玩家是一枚骰子，
那念头的价值根本测不出来。头一版就是这么跑的，结果 A 高达 48.9%，
而 B 只有 1.1%。

## 需求、愿望、念头是三样东西

「想吃饭」「想离开」「想活久一点」「我要修仙」——它们不是同一种心理状态。

```text
需求　有对象，有期限，会过去。而且它逼着你做事
      家里有人病重，要救命

愿望　没有对象，也没有方向。它只是一种模糊的想要
      想活久一点

念头　有方向。它改变你注意什么、愿意试什么
      想学看病 / 想弄明白 / 想守着家
```

这个区分是有代价才立起来的。从前「想活久一点」被当成一个念头，
于是它得有 `echoes`——可一个只是**怕死**的人在山上、在镇上、在家里
到底会多做什么？答不上来。**因为它根本不指向任何行动。**

所以愿望**没有 `echoes`**：它不改变他注意什么，它只是攒着，
直到某一天分岔成一个真正有方向的念头。

### 同一个愿望通向五个地方

而**分岔往哪儿走，取决于他手边有什么**：

```text
【给家里抓过药的孩子】
    你开始留意郎中怎么看脉、怎么开方。你说不出为什么。
    → 你想学看病。

【听说过山里那种人的孩子】
    有人说那种人不吃不喝也能活。你想的是「活」那个字。
    → 你想弄明白那些说不通的事。

【家里那个人一直没缓过来】
    家里那个人一直没缓过来。你把能担的都担了。
    → 你想把日子过安稳。

【被那只凉手抓过腕子的孩子】
    左腕那圈疤在阴天会痒。你开始留意谁的身手好。
    → 你不想再被人按住。

【什么也没接触过的孩子】
    你想过这件事很多回，每回都想不出个头绪来。
    → 什么也没通向
```

### 而最常见的结果是哪儿也没去

真实人生里（`scripts/wishes.ts`，1500 世，其中 460 世攒到过分岔门槛）：

| 通向了哪儿           | 占比    |
| -------------------- | ------- |
| **什么也没通向**     | **57%** |
| 想弄明白那些说不通的 | 23%     |
| 想学看病             | 13%     |
| 想把日子过安稳       | 7%      |
| 不想再被人按住       | 0 个人  |

分母是那 460 个攒到门槛的人。最后一档不是一条没写的路——它要求这辈子
被那只凉手抓过腕子，而那件事本身三百世里才八个人，一千五百世也没轮到
一个既撞上它、又在分岔那一掷里选中它的人。

所以走查不报「通向了四个地方」，报的是**「抽到 4 种，一共 5 种」**：
前一个数掉了是抽样的事，后一个数掉了是内容的事。而后一个数是从
`WISHES` 里**数出来**的，跟跑多少世无关。

这张表从前是四百世跑的，中间两档连跑三批落在 19 / 29 / 23 和 19 / 10 / 13——
摆动一倍，读起来像有人改过内容。一千五百世连跑两批，四档的差都在两个点以内。
可**加世数买得到「常见的那几档稳下来」，买不到「罕见的那一档出现」**：
一千五百世那一格照样是零。它的可达性由另一处交代——
走查第三节直接把那个旗标设进去走一遍。

门禁守的不是这几档各占几成，而是「一共通向三个以上的地方」和
「没有哪一条占到七成」。**攒到门槛的人全都分岔了**：
筛人的不是分岔这一步，是它通向哪里，而最常见的去处是哪儿也没去。

**若一个愿望必然通向某一条路，那条路就是系统偷偷安排的主线。**
而这里最常见的结果是：他就是怕，而且一辈子不知道能怎么办。

这一半靠的是分岔时的那一道闸——**手边有路，不等于他找得到**。
同样想活久一点、同样听说过山里那种人，有的人会把两件事连起来，
有的人一辈子也没连上。没有这道闸，凡是听说过修士的人都会必然走上那条路。

### 需求这一层不新建数据结构

「家里有人病重」由旗标和一卷世界事件承载就够了。它真正的价值在于
**它是愿望的来源**，不在于它自己被记住——再加一层存储只会让
三个概念互相打架。

那一卷（`need:illness`）也守着老规矩：**病好不好，跟他守得多勤无关。**
掷一次，六成好了、三成落下病根、一成没熬过去。他的选择改变的是
自己经历了什么，不是把结果掰成对他有利的那一种。

### 「我要修仙」将来在哪一层

在念头那一层再往前长一步。**它不该凭空生成**——

```text
亲人病重　　　→　需求
听说修士寿长　→　愿望：想活久一点
知道确实存在　→　念头：想弄明白修行
开始主动寻找　→　方向：想修仙
```

而上面那张表说明：走到第三步的只有 23%，
走到第四步的会更少。**修仙是人生的一条路，不是所有人的终点。**

## 修行的第一关不是学不会，是不知道去哪找

上一节把「想弄明白修行」这个念头造出来了。这一节问的是下一句话：
**然后呢？他能做什么？**

答案是：打听。他没有别的办法。而这一册刻意不碰功法、炼气、灵根、境界——
**那些是门里的事**，这一册讲的是一个人怎么走到门口，
而绝大多数人一辈子也没走到。

### 他听到的东西里，假的占六成

`src/content/leads.ts` 里十条消息，权重摊开来是这个样子：

| 真伪                   | 占比 |
| ---------------------- | ---- |
| **假**                 | 61%  |
| 半真（方向对，细节错） | 19%  |
| 真                     | 20%  |

这不是配平出来的数，是立场。而更要紧的一条是**假的讲得比真的还清楚**：

```text
〔假〕三十年前有位陆真人，在城东白石桥下点化过一个卖炭的。
〔真〕每年三月总有几个外路人往上走。上去的没见下来过。
```

编的人不需要顾忌事实，所以他有名有姓、有地名、有年份，还带一句诗。
而那条真的，说话的樵夫自己都不知道那是什么——**最好的真线索
往往来自一个毫不知情的人。**

写新线索的分寸就在这儿：若假线索写得一看就假，玩家就有了
一个引擎没打算给他的工具。

### 他手里只有两样工具，都要花时间，都可能白花

**一是跑一趟。** 世界怎么回应，只看那地方到底是什么——
去一个不存在的地方就是扑空，其中三成半还会在那儿撞上个等生意的人
（去那种地方的都是他这样的，而那正是骗子挑地方的道理）。

而**真地方也未必看得出来**。它没有牌子，也没有人迎出来，
心思不够细的人会觉得那只是一座山、一间关着的屋，在底下待两天就走了。

**二是听第二个人说同一件事。** 他分不出真假，可他数得清有几个人
指了同一处地方——假消息各说各的，真消息会撞在一起。
这也不是保票：说书人那一段和卖符的那一段照样可能凑巧撞上，
那时候他会满怀把握地跑去一个根本不存在的地方。

### 五种结果，其中最常见的是什么也没找到

`scripts/seeking.ts`，4000 世：

| 结果                          | 占比    |
| ----------------------------- | ------- |
| **C　什么也没找到**           | **93%** |
| E　找到入口，人家没收         | 约 3%   |
| B　找到的全是假的，或者跑空了 | 约 2%   |
| A　找到真线索，并且进了门     | 约 1%   |
| D　找到入口，自己没进         | 约 1%   |

走到门前的一共 5%。而 C 里头约七成人其实**听到过东西**——
他攒了三五件说不清的事，只是没有两件对得上。

> **手里有几句话，跟找到线索是两回事。** 没有两条撞在一起，
> 他就没有任何理由动身。跟一句也没听着的人比，他多的只是几件心事。

### 可是没有人会玩四千世

上面那张表量的是**分布**，而分布不是玩家会经历的东西。
一个人大概玩十世。1% 那一格在四千世里是四十个人，在十世里通常一个也没有——
也就是说，**那件事对绝大多数玩家等于不存在**。

所以走查最后一节把每一格都换算到十世的尺度上，问一个不同的问题：
**玩十世的人，有多大概率见过一次？**

| 结果                          | 十世里至少见过一次 |
| ----------------------------- | ------------------ |
| C　什么也没找到               | 100%               |
| E　找到入口，人家没收         | 约四分之一         |
| B　找到的全是假的，或者跑空了 | 约两成             |
| A　找到真线索，并且进了门     | 约一成             |
| D　找到入口，自己没进         | 约一成             |

**玩十世，站到过一次门前的是四成。** 另外六成的人玩完十世，连门口都没见过。

这张表写的是约数，不是量不准，是**量到这个精度就够了**——
「玩十世大概能撞见一回」和「9% 还是 13%」，对读的人是同一句话。
而这一节从前差点毁在相反的一头：见「[走查会撒的几种谎](#走查会撒的几种谎)」第六条。

而那十世读起来是这样：

```text
 1　〔C〕听着 1 件事，没有两件对得上。哪儿也没去。
 2　〔B〕两条对上了，跑了一趟——不是那么回事。
 3　〔C〕听着 1 件事，没有两件对得上。哪儿也没去。
 4　〔C〕听着 1 件事，没有两件对得上。哪儿也没去。
 5　〔C〕听着 1 件事，没有两件对得上。哪儿也没去。
 6　〔C〕听着 1 件事，没有两件对得上。哪儿也没去。
 7　〔C〕听着 1 件事，没有两件对得上。哪儿也没去。
 8　〔C〕问了几年，一句也没问着。
 9　〔C〕听着 2 件事，没有两件对得上。哪儿也没去。
10　〔C〕问了几年，一句也没问着。
```

十世里多半整整齐齐全是 C。**而那正是这一册要的样子**——
一个人打听了一辈子什么也没打听着，是常态，不是失败。

### 门前那一下，他到死也不知道人家凭什么

走到门前的人，那个人会让他把手伸出来，两根指头搭在腕子上停两息，
然后说一句话。引擎看的是 `root`——**那个数在他出生那一刻就定了**，
跟出身、跟努力、跟他有多想都没有关系。王府的孩子和农户的孩子
在这一掷上平等，而两个人谁也不知道自己那一个数是多少。

```text
〔差得远〕你回去吧。这条路不是人人走得。
〔差一点〕差得不多，可差着就是差着。
```

两句话的分量完全不同，可结果一模一样。**而他连自己是哪一种都不知道。**

灵根排在最后一步不是偶然：先是你为什么想修仙，再是你愿意付出什么，
然后是有没有机会接触，**最后才轮到有没有资格**。
一个天生资质极好、却从没听说过修士的人，这几卷一辈子碰不上。

### 入场只看念头，不看资质

```ts
requires: [{ knowledge: 'cultivators-exist' }, { flag: { key: 'leaning:know' } }]
```

条件里有一个念头，这是合法的——判据是那条老规矩：
**这一卷写的是世界发生了什么，还是他做了什么？** 「他逢人就绕着弯问」
是他自己的行动，当然要看他心里想什么。而「镇上招短工」那种世界发生的事，
条件里一个念头也不许有。

### 走查自己撒的两次谎

**一、把 C 判成了 A。** 头一版把「听着几件事」算作找到线索，于是 A 有 6%。
可那些人哪儿也没去过——**材料不是结果**。改判之后 A 掉到 1.1%，
而那才是真的。

**二、变量偷偷相关了。** 头一版里「他问了几年」和「他到门前进不进」
都从循环下标 `i` 派生，结果问得少的人恰好也是不进门的那一批，
于是 D 那一格永远是空的，看上去像是「没人会走到门前又掉头」。
**走查里的每个变量必须各掷各的。**

> 这两条和后来栽的另外五条一起收在末尾的[走查会撒的几种谎](#走查会撒的几种谎)。

## 时间是唯一真正稀缺的东西

年龄不是点「下一年」加上去的，它就是时序本身（`age = year - 1`）。
时间随人生行为推进：读书消耗数月，赶一趟远路十几日，生一场病过去半个月，
在私塾念一年就是一年。选项右侧常驻「耗 一年」「耗 半月」——**账要在落笔之前就看见。**

## 机缘不是幸运抽奖

> 机会出现在你面前，但你是否能够发现、理解、抓住它，是另外一回事。

山道上躺着一个人。他是猎户、江湖武人、宗门弟子、修士、邪修，还是已经死了——
在你抬头之前，`roll` 就已经把它掷定并写进旗标了。你的选择改变的是自己撞上什么，
**不是把他变成对你有利的那一种。** 玩家永远看不到这一掷。

而心思不够细、也不常在山里走的人，正文里根本不会提有人躺着。他这一生都不会知道错过了什么。

### 五个可以断的节点

这一场不是「注意 → 选择 → 既定结果」，是五节，每一节都断得掉：

```text
注意 → 理解 → 兴趣 → 行动 → 世界回应
```

#### 注意那一节从前是一行阈值，而它量出来是个满格

```ts
insight >= 34 || body >= 52 // → 看见了
```

读起来像「机会摆在面前，看不看得见是另一回事」，实测三百世里
**三百个人全都看见了**。十一种出身里只有农户两项都够不着，
可童年那些事——下地、跟车、认药——到十岁之前就把属性推过了线。
这一关被童年系统提前替他解决了。

**一个满格的过关率读起来像「这一关很宽」，其实是「这一关不存在」。**

修法不是把线抬高。抬高只换来另一句话：聪明孩子看见，笨孩子看不见——
那是能力检测，不是人生。要问的不是他聪不聪明，是

> **当时的他，有没有把注意力放在那里。**

这两件事不一样。心思很细的孩子，在挨过一顿骂、满脑子想着家里那个
还没退烧的人的下午，一样什么也看不见；而笨手笨脚的猎户家孩子，
在他走了十几年的那条山路上，眼角一扫就知道草丛被压过。

所以 `attend()` 的分数由三样合起来定，`insight` 只占一份，而且不设阈值：

```text
心思细不细　+　那天他心里装着什么　+　路上是什么天
```

后两样全都来自他这一生真发生过的事：家里有人病着（−11）、欠着账（−6）、
走了大半日（−6）、下雨或起风（−8）、常年在山里走（+10）、
上回也走过这么一段（+8）、心里正想弄明白些什么（+6）。
**每一条都指名道姓说得出为什么，没有一条是「运气不好」。**

于是「没看见」不再是一格，是三格——它们在人生意义上完全不同：

| 落点                  | 他那天                           | 400 世 |
| --------------------- | -------------------------------- | ------ |
| `unseen`              | 没有注意到                       | 约 24% |
| `noticed-but-ignored` | 看见了，但没放在心上             | 约 22% |
| `misread`             | 看见了，理解成另一回事，绕开走了 | 约 11% |
| `interest`            | 停了下来，于是有得选             | 约 43% |

而最要紧的一节是**同一个人不同的一天**——属性一分不差，只换当天状态：

```text
十岁那年　　刚挨过骂，心里想着家里，起着风　　看进去 10%　瞥一眼 22%　没看见 68%
十五岁那年　一个人在山里走惯了，晴天　　　　　看进去 75%　瞥一眼 20%　没看见  5%
```

**「错过机缘」于是成了人生的一部分，而不是属性不足。**

那件压着他的事会印进正文，**三条路上都印**。所以哪怕他什么也没看见，
读到的也不是一片空白，而是「你心里想着家里那个人」——
他知道自己那天心不在焉，只是永远不会知道自己错过了什么。

> 这一层的代价是明知故犯的：它把「这辈子拿到过那册书」从 8.3% 压到 3.9%，
> 「多年以后有人点破」从 2.7% 压到 1.8%。那一关从前不存在，
> 而「机会摆在面前，看不看得见是另一回事」这句话，得有人真的看不见才算数。
> 分布归 `scripts/attention.ts`，漏斗归 `scripts/probe.ts`（一千二百世）。

**理解那一节可以错，而且错得讲得通。** `glance()` 不是随机发错答案——
判断从见识里长出来：见过血的人读成「伤了」，镇上长大的孩子读成「喝多了」，
心思细的人看出「他衣裳料子太好，腰上挂的东西没见过式样」。
读出「不对劲」不需要听说过修士——**「不对劲」和「那是修士」是两回事**，
听说过只是让这条路更好走。

**兴趣那一节由玩家自己决定，引擎不掷。** 没有悟性检定，没有气运加成。
四个选项摆在那里：扶起来、走近看看、跑回村里叫人、不关自己的事。

**世界回应那一节刻意不看 `fortune`。** 用气运决定机缘成不成，机缘就还是抽奖。
`resolve()` 看的是这个动作、这个人伤得多沉、你这具身子骨、你花了多少时间。
于是会出现：body 70 的人扶不动一个修士——那件事根本不取决于力气；
而「跑回村里叫人」是最稳的一条路，却要走大半天，等你带人回来，
能走的都已经走了。**每条路都有它自己会输的地方。**

`scripts/wounded.ts` 拿这六种人生当验收（4000 次）：

| 人生                               | 占比   | 它证明的事         |
| ---------------------------------- | ------ | ------------------ |
| A 判断对 → 行动 → 成功             | 约 15% | 机缘抓得住         |
| B 判断错 → 行动 → 才发现自己错了   | 约 40% | **理解可以错**     |
| C 判断错 → 没兴趣 → 一生不知道真相 | 约 21% | **机会不等于命运** |
| D 判断对 → 行动 → 但没做成         | 约 5%  | **行动不保证结果** |
| E 判断对 → 没兴趣 → 走开           | 约 9%  | 看穿了也可以不管   |
| F 判断错 → 行动 → 回应完全超出预期 | 约 9%  | 世界不按你的剧本走 |

这张表从前写的是「300 次」和一串小数——**那个精度不存在**。
D 占五个点，三百次里十一二个人，连跑三批报 3.3 / 5.0 / 5.7。
四千次跑完七秒，换来的是这张表说的话跟它印出来的位数对得上。

同一支走查还钉着两条铁律：把 body 和 will 按住只让气运变，
气运 20 / 50 / 80 三档的成功率**差 0 个百分点**；
而 body 30 → 70 对猎户、武人、弟子都是 0% → 100%，对修士始终 100%——
**力气有用，但不是对所有人都有用，而玩家做决定时并不知道躺着的是谁。**

> 头一版按气运分桶跑，差了 20 个百分点，看着像气运在插手。
> 其实是混杂：`fortune` 和 `body` 都来自出身，气运低的多是农户猎户，
> 而他们身板硬朗扶得动人。量的根本不是气运。**走查本身也会说谎。**

真相与认知分开写进存档（`wounded-man` 是世界事实，`wounded-reading` 是玩家认知），
所以多年以后可以有一次「原来那天遇见的是修士」——
**而如果你一辈子没走过去，这一句就永远不会出现。** 你到死都以为那是个醉汉。

## 多年以后才明白当年发生过什么

山道那一场的误读，伸手就被戳破：你以为是醉汉，他睁开眼，你当场知道自己错了。
庙前货郎那一册书走的是**相反的路**——

```text
看见书 → 判断这是什么 → 是否在意 → 是否取得 → 揣十年 → 后来重新理解
```

### 抓住机会 ≠ 当场获得答案

你翻了两页，心里有了个判断。那判断从你的见识里长出来，
而**出身直接决定它的形状**：同一册符书，走查里——

| 谁                   | 他看见的是                                       |
| -------------------- | ------------------------------------------------ |
| 药铺的孩子           | 药方 34%　废纸 18%　值钱的 15%　古怪的字 15%     |
| 商户的孩子           | 账册 32%　废纸 20%　古怪的字 18%　值钱的 14%     |
| 农家的孩子（认字）   | 古怪的字 23%　废纸 23%　账册 17%　值钱的 16%     |
| 农家的孩子（不认字） | 废纸 45%　值钱的 35%　不该看的 21%               |
| 心思很细的孩子       | 古怪的字 36%　不该看的 19%　值钱的 14%　账册 14% |

药铺的孩子从小认药，看见手抄本第一反应是方子；成天见账的人家，一行一行的就是账；
不认字的人根本走不到「这些字很怪」那一层——**他这一生都不会知道自己错过了什么。**

然后你决定要不要在意。`interest` 那一节的四个选项**一个条件也不带**：
把它当废纸的人照样可以买下，看出「不该声张」的人照样可以怕惹事走开。
兴趣是玩家的事，引擎在这里不掷骰、不做判定（这一条做成了走查里的静态检查）。

### 错误会跟着你走十年

买下之后，行囊里那件东西用的是**你自己给的名字**，不是它真正的名字。
往后每隔一阵拿出来翻一次，一次也没看懂，于是最初那个判断一年比一年结实：

```text
〔猜想〕像是哪家铺子的旧账本。      ← 十岁那年
〔确信〕就是哪家铺子的旧账本。      ← 揣了几年之后
```

**这一步只加固，不修正。** 引擎在这里只升 `grasp`，`mistaken` 一个字不碰——
他更确信了，但他没有更接近真相。直到十六岁那年渡口上有人扫了一眼：

- 山道上那个濒死的人塞给你的那册 → 「炼气法门。」
- 庙前几文钱买的那册 → 掷出来的六种真相各说一句：
  「符书。写坏的。」／「账。北边的号，早没了。」／「方子。抄漏了。」／
  「废纸。谁家的旧簿子。」／「收起来。别叫人看见。」／「……哪来的。」

六种收梢的余味完全不同：写坏的符书是白揣了几年，残卷是从此有了一件要追下去的事，
禁书是背上了一样甩不掉的东西。`reveal` 改名时把旧名字留在 `formerName` 里不删——
**那些年是真的，不该被新知识抹掉。**

### 走查（`scripts/book.ts`，2000 次）

买下并揣着的人里 **七到九成揣的是一个错的理解**（六种真相各不相同，
最容易读错的是药方 88%，最不容易的是残卷 70%）；其中约六成在渡口那天被纠正，
其余的带着它走完了这一卷。一共长出 **13 种不同的认知历史**：

```text
24.3%  走开了，一生不知道
11.8%  揣了多年，后来知道那是废纸
10.0%  揣了多年，后来知道那是符书
 7.8%  揣了多年，后来知道那是账册
 6.3%  揣了一辈子，始终以为是「上面的字笔画清楚」
 ……
```

这张表从前标着「300 次」。三百次下表尾那几行是二十来个人，
σ 一个半百分点，而它写到了小数位——**这一支跑两千次要六秒，
跑三百次要五秒**：省下的那一秒买不到任何东西，赔进去的是这张表说话的资格。

还有一条：**问错了问题，会把你领到别处去。** 你以为那是账册，
就会去问「这是哪家铺子的账」——货郎说他不识字，倒说出这叠纸是从西头
一户破屋里收的，那家男人是外路来的。你没问出书的来历，问出了一户人家。

## 认知有三根轴，不是一道坡

「知道」从前是一道单一的坡：听说 → 见过 → 猜想 → 确信 → 亲历。
可那道梯子**混了两个不同的轴**——听说、见过、亲历说的是他跟这件事离得多近；
猜想、确信说的是他形成了什么样的解释。两者根本不在一条线上。

最直接的证据：一个亲眼看见修士踩水而过的孩子，在老梯子上的档位
竟然比一个坐在家里瞎猜的人还低。而他真实的状态是——**离得最近，却什么也没弄明白。**

拆开之后是三根各自独立的轴：

```text
接触　听说 → 见过 → 亲历　　只能往上
解释　未理解 → 猜想 → 确信　可以往下
对错　对 / 错　　　　　　　　跟前两根都正交
```

一正一反两条规则，缺一不可：

- **接触只能往上。** 听人说一嘴，推翻不了亲眼见过。
- **解释可以往下。** 一句「不是那么回事」就能让一个确信多年的人重新不敢肯定。

九格乘对错十八种，**全部合法**：

| 　       | 未理解                       | 猜想    | 确信        |
| -------- | ---------------------------- | ------- | ----------- |
| **听说** | 只听过这个名字               | 对 / 错 | 对 / 错     |
| **见过** | **他看见了，可他不明白**     | 对 / 错 | 对 / 错     |
| **亲历** | 他就在场，至今说不出那是什么 | 对 / 错 | **对 / 错** |

「亲历」不是真相保票——世上最难劝的正是那种「我亲眼见过」的人。

### 被人说动之后有三种样子

只做「纠正」的话，NPC 一开口玩家的世界模型就被改对，那还是百科系统。
现实里的认知变化至少有三种，而且对玩家的体验完全不同：

```text
① 动摇　　　　「你这么一说……我也不敢肯定了。」
              解释退一档，说法一个字没改，错也还是错的。

② 有了别的说法「也可能不是修士，是某种江湖把式。」
              新说法跟原说法并排放着，不覆盖。他从此心里有两个版本。

③ 明确纠正　　「原来那天见到的确实是修士。」
              只有这一步才抹掉错误标记。
```

### 认知历史本身就是内容

每一次变化都往 `history` 里追加一条，旧的绝不删：

```text
〔初识〕　　　　听说 · 确信　　修士就是江湖上很厉害的人。
〔有了别的说法〕听说 · 猜想　　修士就是江湖上很厉害的人。
                              另有一说：走北路的商旅说，他们不是江湖人。
〔加深〕　　　　听说 · 确信　　修士是另一种江湖人吧。
```

注意最后那一步：**他采信了商旅的话，却把它塞回了自己原来那个框里。**
一条一路被改到「对」的知识条目，跟一个人真实的理解过程毫无关系。

### 拆分时揪出的两个真 bug

都是「档位越高越接近真相」这条隐含规则的产物：

- **升档会静默抹掉 `mistaken`。** 于是「更确信自己那个错的」在引擎里做不到——
  而那恰恰是人最常干的事。
- **同档位的纠正进不来。** 他确信那是账册，有人当面告诉他那是符书，
  引擎当成「已经知道了」，脑子里那条纹丝不动。

现在「他变得更确信了」和「他终于弄明白了」是两次不同的调用：
不传 `mistaken` 就不动对错，传 `null` 才是明确纠正。
整套钉在 `scripts/grasp.ts` 里，失败非零退出。

## 一个人的理解，是另一个人的局部世界

前两支机缘验的是玩家跟**世界**打交道。山道上躺着的虽然是个人，
可对玩家而言他跟一册书没有区别：不会争辩，不会含糊其辞，不会自己就理解错了。

走北路那个商旅不一样。他会来很多次，会记得你，也会老。
而最要紧的是——**他对世界的理解，可能本身就是错的，而他不知道。**

### 从世界真相到玩家脑子里那句话，隔着三道关口

```text
世界真相
  ↓  ① 商旅自己怎么理解的（他可能就错了，而他不知道）
他心里那句
  ↓  ② 他肯说多少、说得多明白（他多半说得很含糊）
他嘴里那句
  ↓  ③ 玩家怎么听的（他会往自己已有的框里塞）
玩家脑子里那句
```

于是有了这一支最要紧的一种结果：**他说的是真话，玩家还是理解错了。**

```text
玩家确信：修士就是江湖上很厉害的人。
商旅想说：不是江湖人。
他只说了：不是一路人。
玩家听成：哦，那就是不同门派的意思吧。
```

没有人撒谎，没有人失误，而玩家的世界模型**更自信了，也更错了**。

### 一个 NPC 的四种状态

| 状态                 | 他说的那句                             |
| -------------------- | -------------------------------------- |
| 知道但今天不想说     | 走远道的事，说了你也不懂。             |
| 真不知道             | 我走了半辈子北路，没撞见过。           |
| 知道且愿意说         | 有一年在渡口，我见过一个人……           |
| **自己错了而不自知** | 北边有个姓卓的，一个人挡过十几号马贼。 |

最后一种最要紧：**他说得最生动**——有名有姓，有地方有年份，
比那个真见过修士的人讲得还实在。他不是骗子，他只是把见过的东西归错了类。

### 越笃定越听不进去

同一个亲眼见过修士的商旅，同一句「不是一路人」：

| 心思 | 他还在猜的时候   | 他已经确信的时候               |
| ---- | ---------------- | ------------------------------ |
| 45   | 有了别的说法 71% | **加深 81%**（更确信那个错的） |
| 60   | 弄明白了 100%    | 有了别的说法 75%　弄明白了 16% |
| 75   | 弄明白了 100%    | 弄明白了 89%                   |

心思 60 的人，只因为原来已经确信，听懂的比例从 100% 掉到 16%。
**这一条才是「越问越错」真正的发条。**

### 关键指标：多谈几次，他离真相更近了吗

三夜谈下来（`scripts/merchant.ts`，2000 次）：

| 结局     | 占比   |
| -------- | ------ |
| **更错** | 约 28% |
| 更对     | 约 27% |
| 没变     | 约 24% |
| 一无所获 | 约 21% |

```text
更错：〔猜想〕修士就是江湖上很厉害的那种人。
     → 〔确信〕修士就是江湖上很厉害的那种人。
```

**更错比更对还多。** 这一条是这支机缘真正要证明的东西：
认知不是越问越对的，而 `mistaken` 也就此从一次剧情判定
变成了人物认知系统的一部分。

> 上表是跑四千次量的。**这个结论比它看上去脆弱**——更错只比更对多 2.2 个点，
> 而走查日常只跑三百次，那个量级下两者会来回翻转。
> 所以走查的门禁押的不是「更错多于更对」，而是「两种都得跑得出来」：
> 一个都没有，才说明多问几次必然更接近真相。
> **门禁要的世数，和一句结论要的世数，本来就不是一回事。**

## 三层信息结构

界面把「玩家知道什么」分成三层，各有各的位置，互不越界：

| 层       | 位置                          | 内容                                     |
| -------- | ----------------------------- | ---------------------------------------- |
| 当前经历 | 中段正文                      | 地点、时间、叙事、对话、行为、结果       |
| 当前状态 | 状态栏 + 人物面板             | 姓名、年龄、所在、身份、家世、他人之言   |
| 世界认知 | 知识 / 人际 / 编年 / 世界面板 | 你听说过什么、见过谁、经历过什么、到过哪 |

## 核心机制：玩家知道什么 ≠ 世界真实存在什么

引擎内部确实有 `Attributes`（根骨、悟性、体魄、心性、气运，0–100），
家境有 `standing` / `debt`，关系有好感度。**但界面永远不显示它们，一个都不显示。**

十六岁的少年凭什么知道自己的「悟性」是多少？他只能知道别人对他说过什么。
一个孩子对家境的全部认识，也只是饭桌上有没有肉——所以人物面板上写的是
「不宽裕，但过得去」，不是「家产 43」。

于是人物面板显示的是 `Aspect`：

```ts
interface Aspect {
  self: string | null // 你自己的认识。多数时候是 null
  claims: AspectClaim[] // 别人说过的话，只增不改，各带时间戳
}
```

先生说「你这孩子，记性比旁人好些」，这句话就永久留在「学识」一栏下，
底下跟一行楷体的疑问：「你不知道这算不算一句夸奖。」

多年以后宗门若说「这种资质……也只能算中下」，那句话会**并列追加**在旁边，
而不是覆盖前一句。玩家自己去发现，当初那个「不错」根本不是自己理解的意思。

为了让数值没有办法再爬回界面，`src/engine/describe.ts` 里
物理删除了 `ATTRIBUTE_LABELS` / `ATTRIBUTE_ORDER` / `describeLevel` —— 没有渲染函数，就渲染不出来。

## 先生说的「聪明」，和修士说的「悟性」不是一回事

评价不是写死的台词，是**算出来的**。链条上每一步都可能失真：

```text
真实属性 → 观察能力 → 观察结果 → 语言表达 → 玩家理解
```

关键在于**一把尺子量的东西不等于任何单个属性**。先生量的「读书快慢」里
记性占七成，修士说的「悟性」才是单独那一样。于是同一个人：

| 谁           | 他说什么                      |
| ------------ | ----------------------------- |
| 周先生       | 记性比旁人好些 / 读书倒是不慢 |
| 坐堂的郎中   | 底子还算不错                  |
| 走镖的把式   | 身子骨还行                    |
| 一名炼气修士 | 悟性一般 / 神魂尚可           |
| 一名筑基修士 | 资质倒是不错 / 悟性不高       |
| 宗门长老     | 资质不错 / 悟性普通           |

六个人都没说谎，量的是不同的东西。

再叠一层判断力（`acuity`）：它不是随机乱猜，而是**往中间拉**——
判断力低的人看不出天才也看不出废物，这正是外行的样子。
走查里炼气修士（判断力 52）看同一个悟性 48 的人一百次，说过三种话：
「一般」53 次、「尚可」33 次、「差了些」14 次。
**他有三分之一概率看走眼，而玩家永远不会知道。**

### 一条铁律：评价不写回属性

修士说「悟性一般」，`insight` 一分不动。评价也永不作为任何 `Condition` 的判据。

那「别人怎么看你」还能影响人生吗？能——**但只经玩家的手，不经引擎的手**：
修士说「资质一般，别浪费时间」，玩家因此放弃，这是真实的人生影响，要它发生。
但那条路始终开着，他可以不信、可以再找人看。

> 世界不因评价而改变，玩家因评价而改变。

## 人是人，不是事件触发器

「父亲」不是插在家庭位置上的一块牌子，是沈怀山这个人——
有名有姓、有年纪、有脾气，比玩家早出生二十几年，
而且**玩家不在场的时候他照样活着**。

父亲离家做工不是 `father = dead`，是这个人换了地方谋生
（`{ place: 邻县·河堤工地, trade: 修河堤的工 }`）。他在那儿老去、生病。
走查里 171 个「父亲离过家」的人生，**0 个父亲从世界上消失**。

那 171 个是这一轮才凑齐的。从前的判据是 `hasFlag('father-away')`，
可 `hasFlag` 的语义是「存在且不为 false」，而**父亲回来那一卷会把这面旗子按回
`false`**——于是「他几年后回来了」的那六成人生，在铁律眼里等于从没离过家。
真被查的只剩死在外面和杳无音信的两档，而那两档本来就会写进册子，
**最不需要担心的恰恰是唯一被查的**。改用他走出村口那一刻必掷的 `father-fate`
之后，归、亡、杳三个出口一个不漏，样本从 27 个涨到 171 个。

关系是**边**不是槽位。做成 `fatherId / guardianId` 的话，
「姐姐当了家」没处放——她既是姐又是抚养人，一个槽装不下两样。
做成边就全免费，而且玩家自己也只是图里的一个节点（`me`），
所以「成年后自己成家」不需要任何新机制。

断了的边不删，只封口：**老乞丐养过你这件事，不因为他死了就没发生过。**

十种出生境况：父母健在 / 有兄姐 / 母亲难产而亡 / 父亲早亡 /
与长姐相依为命 / 跟着兄长 / 叔父收养 / 庙门口的弃儿 /
老乞丐捡回来的 / 战乱失散。弃儿的生父生母不是「未知」这个值，
是那两条边**根本不存在**——跟「爹死了」是完全不同的两件事。

## 体质不是 debuff，是人生的形状

跛脚的孩子下不了地、走不了山道，可他常年在屋里，摸到书的机会比谁都多
（`body -26`，但 `memory +10 / insight +6 / will +10`）。
没有一种体质是净减的。

而 `root`（修行资质）与 `spirit`（神魂）一律不碰——
**一个瞎子可能是天生的修行胚子。**

这也是「哪个开局最强」的堵法：不给苦出身发补偿，
而是让决定你能走多远的那样东西跟出生境况完全无关。
走查里有血亲的人 `root` 中位 51，一个血亲也没有的中位 50——差 1 分。

## 选择的三种状态

| 状态 | 写法                                  | 表现                                                        |
| ---- | ------------------------------------- | ----------------------------------------------------------- |
| 可用 | 无 `requires`，或条件已满足           | 墨色，`○` 前缀，可点                                        |
| 锁定 | `requires` 不满足 + 写了 `lockedHint` | 淡墨，`aria-disabled`，右侧灰字写明「三枚铜钱换不来一句话」 |
| 隐去 | `requires` 不满足 + 没写 `lockedHint` | 整条不渲染                                                  |

写不写 `lockedHint` 是设计决策：**够不到但该让人看见的门**要写，
**看见就等于剧透的路**不写。渡口那一卷里，「你想起有人跟你说过这样的船」
对没听过修士的人整条隐去——他连这里有一条路都不该看见。

锁定项用 `aria-disabled` 而不是 `disabled`，键盘用户仍然能聚焦读到提示。

## 走查

门禁只能证明代码编译得过，证明不了「一生走得通」。`scripts/simulate.ts`
把引擎当纯函数用，随机替玩家落笔跑一千世。当前数字：

| 观察项                     | 值                                    |
| -------------------------- | ------------------------------------- |
| 走到卷终（不卡死、不空转） | 100%                                  |
| 进过私塾                   | 约 90%（农户约七成，城里人家近 100%） |
| 父债链走到父亲死           | 约 4%                                 |
| 在渡口认出修士             | 约 16%                                |
| 身上有东西被人点破         | 约 16%                                |
| 收尾年龄                   | 16–17                                 |

一千世要跑将近两分钟，是全套里最慢的一支。慢有慢的道理：
它是唯一一支真把一辈子走完的，而世数不是拍脑袋定的，
是照最稀那一格——**父债链只占四个点，两百世里是七八个人，
量出来的小数位纯属虚张声势**。

这几个数是调出来的，不是碰巧。三处只有跑起来才暴露的问题：

- 最初一版里农户七岁时家境中位数只有 19，够不到私塾门槛——
  **占人口一半的农家子在出生时就被结构性地关死了读书这条路**。
  补上「好年景」这一卷之后中位数回到 45。
- 加完宗室，加压走查发现**一个被削爵的王爷会掉进农户剧本**——
  「父亲每天傍晚去地里站一会儿」，可他家没有地。
  父债链的入场条件原本只看家境不看出身，破产的商户、官宦一样会掉进去。
  现在这条链限定农户，别的出身破落下去该有别的样子。
- 宗室的坠落原本 100% 发生，等于剧本而非命运。
  改成七岁开蒙那天掷一次「court-fate」，四成会塌，六成不会。
- 改 `omen:wounded` 时删掉六个旧结局节点，连带删掉了挂在上面的 `thin-book`
  和 `touched-by-wicked`。前三道门禁都查不出来——边是通的，断的是前置条件。
  现在这类东西由结算函数携带（`Outcome.grants` / `Outcome.marks`），
  不再散落在场景数据里，第四道门禁盯着它。

**总量走查看不出这些。** 王府在一千世里只掷出二十来次，
所以 `scripts/royal.ts` 绕开权重把出身钉死，各跑三百世。

### 走查会撒的几种谎

它跑出来的数字有小数点，看上去就像真的。这些是真栽过的：

**一、量的是另一个变量。** 机缘那一支按气运分桶跑，成功率差了 20 个百分点，
看着像气运在插手机缘。实际是 `fortune` 和 `body` 都来自出身，
气运低的多是农户猎户，而他们身板硬朗扶得动人。把 body 按住只让气运变，差距降到 0。

**二、把材料判成了结果。** 「听着几件事」被算作找到线索，于是 A 有 6%。
可那些人哪儿也没去过——**材料不是结果**。改判之后 A 掉到 1.1%。

**三、变量偷偷相关了。** 「他问了几年」和「他到门前进不进」都从循环下标 `i`
派生，于是问得少的人恰好也是不进门的那一批，D 那一格永远是空的。
**走查里的每个变量必须各掷各的。**

**四、孤儿分母。** 一次批量下调世数，改了循环上界却漏了十一处写死的分母——
除以 2000，实际只跑了 300。数字照样打印，只是全错。
**凡是从常量推算出来的数，都得跟着那个常量自己走，一处也不许抄。**
同类的还有：走查里写 `peakOf('leave') >= 15`，把门槛的值抄了一份，
门槛后来提到 18，这一行就跟别处对不上，报出「1500 世里没有一个人动过念头」。

**五、读的是文字，不是方向。** 反向火种把念头压下去时往往顶上来另一个，
而引擎给这两笔用的是**同一个 moment 对象**——于是被顶上来的那个念头，
它的记录里也留着同一段话。走查只比对文字，就报出「『你想把日子过安稳』
被压过 80.9%」，可反向火种里压根没有一条压它的。
**那个数字是把「因为它被顶上来」整个读成了「它被压下去」。**

**六、把样本量砍成了报出来的尺度。** 「没有人会玩八千世」这句话是对的，
可它说的是**报什么**，不是**量多少**。`seeking.ts` 一并把世数从八千砍到四百，
理由是「四百世够看清形状了」——不够。A、D、E 各占一个点上下，
四百世里各是四五个人，抽多抽少差出一倍，于是「玩十世能见到 A 一次」
连跑两批，一次报 5%，一次报 14%。**砍样本量毁掉的，
恰恰是那张要给玩家看的表。** 换算到玩家尺度，和把数量准，是两件事。

**七、规矩写在文档里，然后文档自己犯了它。** 上面那句「总量走查看不出这些，
王府一千世里只掷出二十来次」是这份 README 自己写的。可往上翻二十行，
「皇子知道有修士的比例是全表最低的」——**那句话读的正是总量走查里
皇室那一行，n=6**。真跑 `royal.ts` 把出身钉死三百世，是 26%：
比农户的 16%、药铺的 21% 都高。写规矩的和引数字的隔着二十行，
就已经互相不认识了。**文档里的断言和代码里的断言一样会烂，
而它没有门禁。**（这一条现在也还是没有门禁，只能靠每轮回头核。）

**八、满格的过关率，读起来像「这一关很宽」。** 山道那支漏斗有三格常年印着
100%，看上去是「这几关不筛人」。翻开来是两回事：

```text
saw-wounded-man / fled-wounded-man / saved-a-man   源码里一面旗子也没有
insight >= 34 || body >= 52                        三百世三百个人全都过
```

前者是判据认错了东西——「看见了人」实际量的是「被邪修抓过」，七个人，
而下一格「拿到书」是十六个，**过关率印出来 229%**。
一个漏斗报出后一关比前一关宽，这本身就是它坏了的证据，
可它印了很多遍，因为**那一支从前一道门禁也没有**。

后者更难看见，因为它印出来的数字是对的：那一行阈值确实人人都过。
可它宣称自己在问「机会摆在面前，看不看得见是另一回事」——
**而一个从不筛人的关卡，和一个不存在的关卡，印出来一模一样。**

于是多了两条规矩：漏斗必须自己查「后一关不许宽过前一关」，
以及**任何一格印出 0% 或 100%，都要当成它可能根本没在量东西**。

### 世数按最稀的那一格定

「跑几世」这个数不是越大越好——它是从最里头那一层反推出来的。

`leaving.ts` 统计的是条件概率，分母是「动过『想离开』这个念头的人生」。
照总世数拍必然出错，可照合格样本拍也不够：一千五百世里合格的九十九世，
而「真的走出去过」只占这九十九世的 5%——**五个人**。
若照「三十个合格样本就够了」去拍，四百世筛出三十几个，最稀那一格期望不到一，
一多半的批次里它根本不出现，走查于是报「这几种人生跑不出来」，
看上去像是功能坏了。

**三个数一层套一层——总世数 → 合格样本 → 最稀那一格。拍板要拍在最里头那一层。**

而当最稀那一格稀到加世数也不划算时（这一支已经是全套里最慢的），
该回头问这一格在测什么。A（走了）和 D（走了又回来）是同一条路上的两种后续，
门禁于是改成问路通不通：**走出去过的人必须存在。**
A 与 D 各自的比例照报不误，只是不再拿它们卡门禁——
**报出来的数字和守住的底线，本来就不必是同一个。**

> 另有一条报数字的规矩：分布既要报原始值，也要报 `1 - (1-p)^10`——
> **一个玩十世的人实际会看见什么。** 没人会去刷两千遍。
> 但这是一条关于**报什么**的规矩，不是关于**跑几世**的：
> 换算出来的那张表，精度是原始那张表给的。上面晃，它跟着晃。

## 视觉约定

设计令牌都在 `src/styles/main.css` 的 `@theme` 里。颜色直接参与信息层级：

- 浓墨 `#23201c` —— 标题、关键信息
- 墨色 `#3d3934` —— 正文
- 淡墨 `#6f6860` —— 次要信息（对比度 4.6:1，达 WCAG AA）
- 极淡 `#a89f92` —— 框线陪衬、树状连接符，不承载文义
- 朱砂 `#9d2f26` —— 关键、危险、当前所在、未读

排版走古籍：宣纸底、双栏框线、印章收尾、`└─` 树状子条目。
但状态栏、面板栏、选项区都有明确边界和状态反馈 —— 它得看起来像个界面，不是一篇散文。

不用角色立绘、地图、装备图标、技能图标。`prefers-reduced-motion` 下所有动画降级。

## 已知边界

### 内容层还欠着系统层

架构已经允许「弃儿、长姐当家、老乞丐养大」，但**内容层的世界观还停在传统家庭上**。
`{elder}` 把硬编码的称呼抽掉了，可那些正文的**内容**仍是照着有爹娘的人生写的——
老乞丐不会「每天傍晚去地里站一会儿」。

真正的解法是给不同抚养结构写专属剧本，那是内容量的问题，不是架构问题。
在那之前，`scripts/verify.ts` 至少保证不会穿帮。

### 刻意不做的事

- **不做 NPC 全人生模拟。** 现在已经有时代、区域、家庭、NPC、关系、认知、
  观察者、事件八层，再给每个 NPC 加日程、职业、收入、消费、情绪、目标，
  很快就会变成一个 NPC 社会模拟器——那不是这个游戏要解决的问题。
  NPC 目前只需满足一条：**他是一个持续存在的人，不是一次性剧情变量。**
  他每天几点吃饭，以后再说。

### 下一步：让玩家也能改变世界

世界已经会自己发生事情了（`worldclock`），但目前只有一个方向：

```text
大旱 → 粮价上涨 → 家里紧起来 → 你被送去做工 → 书念不成了      ✅ 已经跑通
玩家成为修士 → 回乡 → 解决水源 → 农业恢复 → 别人的人生改变    ⬜ 还没有
```

### 别的

- 走到十六岁「卷终」就没有后续了。炼气、宗门、师承、丹器都还没有。
- **只有农户有完整的破落链。** 猎户、匠户、商户、客栈这些家道中落该长什么样，
  还没写。它们现在只有各自的行当机缘。
- 性别只在两处真正分岔：宗室封号，以及「本朝女子不应举」。
  别处一律不分——不是因为古代女子的人生和男子一样，而是因为写一半比不写更糟。
- `Condition` 只有 AND，没有 OR 和否定。需要「非」时得靠 `branches` 兜底分支，
  或者反过来在正向路径上留一个旗标（`riverman` 的「支开跟着的人」就是这么绕的）。
- `chronology.ts` 的链优先是「只要链上有候选，散事件全无机会」，等于链上那件事必然发生。
  所以父亲的生死、宫墙塌不塌，都改成提前用 `roll` 掷定——这是绕过去的，不是解决掉的。
- 没有单元测试。`scripts/` 下那八支脚本顶了大部分回归的活，
  但它们查得出「跑不通」和「比例不对」，查不出「某一句话写错了」。
